# Lecture Slide Explainer — 강의 슬라이드 한국어 해설 생성기

## 목적

강의 슬라이드 PDF를 슬라이드별로 읽고, 각 슬라이드의 내용을 한국어로 상세하게 해설하는 마크다운 파일을 생성한다. 단순 번역이 아니라, 배경 지식·예시·맥락을 포함한 **학습용 해설 문서**를 만드는 것이 목표다.

## 작업 흐름

### 1단계: PDF 읽기

PDF skill을 활용하여 슬라이드 PDF의 텍스트를 추출한다.

```python
from pypdf import PdfReader

reader = PdfReader("slide.pdf")
for i, page in enumerate(reader.pages):
    text = page.extract_text()
```

텍스트 추출이 불완전한 경우(수식, 도표 등), Read 도구로 PDF를 직접 시각적으로 확인한다. 슬라이드 PDF는 보통 페이지당 1슬라이드이므로 페이지 번호 = 슬라이드 번호로 매핑한다.

### 2단계: 해설 문서 작성

추출한 내용을 바탕으로 아래 형식에 따라 마크다운 파일을 작성한다.

### 3단계: 파일 저장

출력 파일명: `[원본파일명].md` (예: `03-type-1.pdf` → `03-type-1.md`)
저장 위치: 슬라이드 PDF와 **같은 폴더**에 저장한다.

## 해설 문서 형식

아래 구조를 따른다. 핵심은 슬라이드마다 원문을 인용한 뒤 해설을 제공하는 것이다.

```markdown
# [강의 제목] - 강의 슬라이드 해설

[과목 정보] — Lecture N

---

## 슬라이드 K: [슬라이드 제목]

### 원문 내용

> [슬라이드의 원문을 blockquote로 인용]

### 해설

**개념 설명**

[핵심 개념을 한국어로 풀어서 설명. 전문 용어는 영어 원문을 병기]

**상세한 예시들** (해당되는 경우)

[구체적인 코드 예시나 수식을 통한 설명]

**배경 지식** (필요한 경우)

[이 슬라이드를 이해하기 위해 필요한 선수 지식 설명]

**전체적인 맥락** (필요한 경우)

[이 내용이 강의 전체 흐름에서 어떤 위치에 있는지]

---
```

## 작성 원칙

### 톤과 스타일
- **한국어**로 작성하되, 전문 용어는 영어를 병기한다 (예: "건전성(Soundness)")
- 교과서 스타일이 아닌, **학생에게 설명하듯** 자연스러운 어투를 사용한다
- 지나치게 딱딱하지 않되, 격식은 유지한다 (합쇼체/해요체 혼용 가능)

### 해설 깊이
- 단순 번역 금지. 슬라이드에 적힌 것 이상의 설명을 제공해야 한다
- 슬라이드의 수식이나 알고리즘이 나오면 단계별로 풀어서 설명한다
- "왜 이것이 중요한가"를 항상 다룬다
- 앞뒤 슬라이드와의 연결 고리를 설명한다

### 예시 활용
- 추상적 개념에는 반드시 구체적 예시를 추가한다
- 코드 예시는 슬라이드의 언어를 따르되, 필요하면 의사코드로 보충한다
- 슬라이드에 이미 예시가 있으면 그것을 더 상세히 풀어준다

### 배경 지식
- 학부 2~3학년 수준의 선수 지식이 필요한 부분은 간략히 보충한다
- 자료구조, 알고리즘, PL 기초 등 관련 배경을 적절히 언급한다

### 슬라이드 유형별 처리
- **제목 슬라이드**: 강의 전체 개요와 목표를 설명
- **정의/이론 슬라이드**: 형식적 정의를 풀어쓰고, 직관적 이해를 돕는 설명 추가
- **예시 슬라이드**: 단계별 실행 과정을 상세히 trace
- **알고리즘/코드 슬라이드**: 각 단계의 목적과 동작을 설명, 에지 케이스 언급
- **요약 슬라이드**: 핵심 포인트를 재정리하고 다음 강의와의 연결 설명

## 주의사항

- 슬라이드 번호를 빠뜨리지 않는다. 모든 슬라이드에 대해 해설을 작성한다.
- 원문 인용은 정확해야 한다. PDF에서 추출한 텍스트를 그대로 사용한다.
- 수식이 깨지는 경우 가능한 한 복원하거나, LaTeX 표기를 사용한다.
- 파일이 길어지더라도 분할하지 않고 하나의 .md 파일로 작성한다.
