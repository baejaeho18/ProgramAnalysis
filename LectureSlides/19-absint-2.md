## 강의 19 전체 조감도 (먼저 큰 그림)

강의 18은 두 세계(구체·추상)와 그 다리(α·γ·갈루아 연결)를 세웠습니다. 강의 19는 그 위에서 **"분석이 건전하다는 것을 실제로 증명하는 방법"**을 단계별로 보여 줍니다. 즉 강의 18이 "건전성의 정의"라면, 강의 19는 **"건전성의 증명 레시피"**입니다.

핵심 줄거리:
1. **건전성의 형식적 정의** — `{|P|} ⊑ γ([|P|])` (구체 의미가 분석 결과의 구체화에 포함됨). 갈루아 연결 덕분에 **이중(dual) 정의** `α({|P|}) ⊑ [|P|]`와 동치 (슬라이드 2~6).
2. **부분의 건전성 → 전체의 건전성** — 분석을 이루는 각 조각(추상 연산 `+̂`, 추상 식 평가 `eval`, 후속 `succ`, 합류 `JOIN`, 전이 `f`)이 각각 대응하는 구체 조각을 안전히 근사함을 **구조적 귀납법**으로 증명 (슬라이드 7~16).
3. **건전성의 일반 정의** — 한 조각이 건전할 조건 `cg ∘ γ ⊑ γ' ∘ g`로 통일 (슬라이드 17~19).
4. **고정점 수준 건전성** — Tarski 정리로 "조각들이 건전하면 분석 전체(최소 고정점)도 건전"임을 증명. 위드닝을 써도 같은 논리 (슬라이드 20~24).

이 강의의 백미는 **건전성 정리(Soundness Theorem)**: `cf ∘ γ ⊑ γ ∘ f`(전이 함수 수준 건전성)이면 `lfp(cf) ⊑ γ(lfp(f))`(분석 결과 수준 건전성)이 따라 나온다. 즉 **"한 스텝의 건전성을 증명하면 전체 고정점의 건전성이 공짜로 따라온다"**는 강력한 모듈성. 증명에 격자·고정점(강의 6)과 구조적 귀납법이 총동원됩니다.

## 슬라이드 2: Formal Definition of Soundness

### 원문 내용
> - Let γ : L2 → L1 be a concretization function where L1 is the semantic lattice and L2 is the analysis lattice
> - An analysis is sound for a given program P if {|P|} ⊑ γ([|P|])
>   - The concretization of the analysis result over-approximates the semantics of the program
> - An analysis is sound if it is sound for every program
> (그림: 𝒫(CState)^n에서 {|P|} ⊑ γc([|P|]), State^n의 [|P|]를 γc로 내림)

### 번역
> - γ: 분석 격자 L2 → 의미 격자 L1 (구체화 함수)
> - 분석이 프로그램 P에 대해 **건전(sound)**하다 ⟺ **`{|P|} ⊑ γ([|P|])`**
>   - 즉 분석 결과를 구체화한 것이 프로그램의 (구체) 의미를 **과근사**한다
> - 모든 프로그램에 대해 건전하면 그 분석이 건전하다

### 해설

**개념 설명 — 건전성의 형식적 정의 ★**

강의 18에서 직관적으로 말한 "건전 = 과근사"를 한 부등식으로 못 박습니다:
$$\{|P|\} \;\sqsubseteq\; \gamma([|P|])$$
- 왼쪽 `{|P|}`: 프로그램의 **진짜 의미**(도달 가능한 모든 구체 상태, 강의 18).
- 오른쪽 `γ([|P|])`: **분석 결과를 구체화**한 것(분석이 "가능하다"고 본 구체 상태들).
- `⊑`(여기선 ⊆): 진짜 의미가 분석이 본 것에 **포함**됨 = 분석이 실제를 하나도 빠뜨리지 않음(과근사).

이것이 건전성의 표준 정의입니다. 분석은 `[|P|]`를 직접 주고, 그것을 γ로 펼쳤을 때 진짜 의미를 덮으면 건전. 예가 슬라이드 3, 이중 정의가 슬라이드 4~6.

## 슬라이드 3: Example

### 원문 내용
> ```
> x = 1; y = 2;
> if input() { z = 3; } else { z = y - x; }
> ```
> γc([|P|]) = γc((..., [x↦+, y↦+, z↦⊤]))
> = (..., {[x↦dx, y↦dy, z↦dz] | dx∈γa(+) ∧ dy∈γa(+) ∧ dz∈γa(⊤)})
> = (..., {[x↦dx, y↦dy, z↦dz] | dx∈ℤ⁺ ∧ dy∈ℤ⁺ ∧ dz∈ℤ})
> ⊇ (..., {[x↦1, y↦2, z↦3], [x↦1, y↦2, z↦1]}) = {|P|}

### 번역
> 부호 분석 결과 `[x↦+, y↦+, z↦⊤]`를 구체화하면 "x>0, y>0, z 임의"인 모든 상태. 이것이 실제 의미 `{[x↦1,y↦2,z↦3], [x↦1,y↦2,z↦1]}`(두 분기의 결과)를 **포함** → 건전.

### 해설

**개념 설명**

부호 분석이 z를 ⊤로 두는 것은 분기에 따라 z=3 또는 z=1(=2−1)이라 부호를 단정 못 하기 때문. γ로 펼치면 "z는 어떤 정수든"이 되어, 실제 두 경우(z=3, z=1)를 모두 덮습니다(`⊇`). 정밀도는 잃었지만(z=⊤) 안전(실제를 포함). 슬라이드 2의 `{|P|}⊑γ([|P|])`가 실제로 성립함을 보여 줍니다. 이 정의의 동치 형태(이중 정의)가 슬라이드 4~5.

## 슬라이드 4: Adjunctions

### 원문 내용
> - Let L1, L2 be complete lattices and α: L1→L2, γ: L2→L1 functions
> - Then the following is equivalent:
>   - α and γ form a Galois connection
>   - α and γ are an adjunction: ∀x∈L1, y∈L2. α(x) ⊑ y ⟺ x ⊑ γ(y)

### 번역
> - α: L1→L2, γ: L2→L1에 대해 다음이 **동치**:
>   - α와 γ가 갈루아 연결을 이룬다
>   - α와 γ가 **수반(adjunction)**이다: `α(x) ⊑ y ⟺ x ⊑ γ(y)` (모든 x, y)

### 해설

**개념 설명 — 갈루아 연결의 동치 형태: 수반(adjunction) ★**

갈루아 연결(강의 18의 확장+축소 두 부등식)은 다음 한 줄의 **동치 조건(adjunction)**으로도 쓸 수 있습니다:
$$\alpha(x) \sqsubseteq y \quad\Longleftrightarrow\quad x \sqsubseteq \gamma(y)$$
직관: "x의 추상화가 y 이하다" ⟺ "x가 y의 구체화 이하다". 두 진술이 같은 뜻 — α와 γ가 순서를 주고받는 짝(수반)임을 보여 줍니다.

**왜 유용한가**: 이 동치 덕분에 건전성 정의를 **양쪽 형태로** 쓸 수 있습니다. `x⊑γ(y)`(γ 형태, 슬2)에 x={|P|}, y=[|P|]를 넣으면 `{|P|}⊑γ([|P|])`, 좌변을 α로 옮기면 `α({|P|})⊑[|P|]`(α 형태, 슬5). 두 건전성 정의가 동치임이 이 수반 관계에서 바로 나옵니다. 증명·계산에서 더 편한 쪽을 골라 쓸 수 있어 강력합니다.

## 슬라이드 5: Dual Definition of Soundness

### 원문 내용
> - Let α : L1 → L2 be an abstraction function
> - An analysis is sound for a given program P if α({|P|}) ⊑ [|P|]
>   - The analysis result over-approximates the abstraction of the semantics of the program
> - (그림: α_c({|P|}) ⊑ [|P|])

### 번역
> - α: 의미 격자 → 분석 격자 (추상화 함수)
> - 분석이 건전하다 ⟺ **`α({|P|}) ⊑ [|P|]`**
>   - 즉 분석 결과가 프로그램 의미의 **추상화**를 과근사한다

### 해설

**개념 설명 — 건전성의 이중(dual) 정의**

슬라이드 4의 수반 덕분에, 건전성을 **α 쪽에서도** 표현할 수 있습니다:
$$\alpha(\{|P|\}) \;\sqsubseteq\; [|P|]$$
- `α({|P|})`: 진짜 의미를 **추상화**한 것(가장 정밀한 추상 표현).
- `[|P|]`: 분석 결과.
- `⊑`: 분석 결과가 진짜 의미의 추상화보다 **크거나 같다**(더 보수적) = 분석이 진짜를 덮음.

슬라이드 2(γ 형태)와 슬라이드 5(α 형태)는 **완전히 동치**입니다(수반). γ 형태는 "분석을 펼쳐 진짜를 덮나", α 형태는 "진짜를 접은 것보다 분석이 보수적인가". 증명할 때 보통 α 형태가 편합니다(추상 격자에서 비교). 예가 슬라이드 6.

## 슬라이드 6: Example

### 원문 내용
> ```
> x = 1; y = 2; if input() { z = 3; } else { z = y - x; }
> ```
> αc({|P|}) = αc((..., {[x↦1,y↦2,z↦3], [x↦1,y↦2,z↦1]}))
> = (..., αb({[x↦1,y↦2,z↦3], [x↦1,y↦2,z↦1]}))
> = (..., [x↦αa({1}), y↦αa({2}), z↦αa({3,1})])
> = (..., [x↦+, y↦+, z↦+])
> ⊑ (..., [x↦+, y↦+, z↦⊤]) = [|P|]

### 번역
> 실제 의미를 추상화하면 z의 값들 {3,1}이 모두 양수라 `z↦+`. 그런데 분석 결과는 `z↦⊤`(분기로 부호 단정 못 함). `+ ⊑ ⊤`이므로 `α({|P|}) ⊑ [|P|]` → 건전.

### 해설

**개념 설명 — 분석이 "더 보수적"이라 건전**

흥미로운 점: 실제 의미를 추상화하면 z=+(실제로 3,1 다 양수)인데, 분석은 z=⊤로 **더 보수적**입니다. 분석은 분기 합류에서 3과 (y−x) 같은 식을 보수적으로 다뤄 ⊤로 갔지만, `+⊑⊤`이라 건전성 `α({|P|})⊑[|P|]`은 성립합니다. **분석이 진짜보다 정밀해선 안 되고(unsound), 같거나 보수적이면(sound) 된다** — 이 예가 그 비대칭을 보여 줍니다. 이제 분석을 이루는 각 조각의 건전성을 증명합니다(슬7~).

## 슬라이드 7: Soundness of Abstract Operation

### 원문 내용
> - Let + : 𝒫(ℤ) × 𝒫(ℤ) → 𝒫(ℤ); D1 + D2 = {z1 + z2 | z1∈D1 ∧ z2∈D2}
> - +̂ is a sound abstraction of + if: γa(x1) + γa(x2) ⊑ γa(x1 +̂ x2)
> - (표: 부호 덧셈 +̂의 결과 — 예: + +̂ + = +, + +̂ − = ⊤, 0 +̂ x = x, ⊥ +̂ x = ⊥)

### 번역
> - 구체 덧셈 `+`: 정수 집합끼리 가능한 모든 합. 추상 덧셈 `+̂`: 부호끼리.
> - **`+̂`가 `+`의 건전한 추상**이다 ⟺ `γa(x1) + γa(x2) ⊑ γa(x1 +̂ x2)`
>   - 즉 "추상값을 펼쳐 더한 것" ⊆ "추상으로 더한 뒤 펼친 것"
> - 부호 덧셈표: `+ +̂ + = +`, `+ +̂ − = ⊤`(양수+음수는 부호 미정), `0 +̂ x = x`, `⊥ +̂ x = ⊥`.

### 해설

**개념 설명 — 추상 연산의 건전성 조건 ★**

분석의 가장 작은 조각 — **추상 연산자**(`+̂` 등) — 가 건전할 조건입니다:
$$\gamma_a(x_1) + \gamma_a(x_2) \;\sqsubseteq\; \gamma_a(x_1 \mathbin{\hat{+}} x_2)$$
좌변은 "추상값들을 먼저 구체화(γ)해서 진짜 덧셈", 우변은 "추상 덧셈(+̂) 후 구체화". **추상으로 먼저 더한 게 더 크거나 같아야**(과근사) 건전합니다.

부호 덧셈표가 그 예: `+ +̂ + = +`(양수+양수=양수, 정확), `+ +̂ − = ⊤`(양수+음수는 부호 모름, 보수적). `+ +̂ −`을 0이나 +로 했다면 unsound(실제로 음수가 될 수 있음). 이 조건이 **모든 추상 연산 설계의 기준**입니다(강의 9의 구간 연산도 이걸 만족해야 했음). 구체 검증이 슬라이드 8.

## 슬라이드 8: Soundness of +̂ — Example

### 원문 내용
> γa(+) + γa(0) = {z1+z2 | z1∈γa(+) ∧ z2∈γa(0)}
> = {z1+z2 | z1∈ℤ⁺ ∧ z2∈{0}}
> = ℤ⁺ ⊑ ℤ⁺ = γa(+) = γa(+ +̂ 0)

### 번역
> `+ +̂ 0` 검증: 펼쳐서 더하면 (양수)+(0)=양수 전체 ℤ⁺. 추상으로 더한 `+ +̂ 0 = +`를 펼치면 ℤ⁺. 양쪽이 같음(`ℤ⁺⊑ℤ⁺`) → 건전.

### 해설

**개념 설명**

`+ +̂ 0`이 건전한지 슬라이드 7의 조건으로 확인: 좌변(펼쳐 더하기)=ℤ⁺, 우변(더해서 펼치기)=ℤ⁺, 같으므로 건전(여기선 정밀도 손실도 없음). 이런 식으로 부호표의 각 칸을 검증하면 `+̂` 전체의 건전성이 확립됩니다. 이 조각이 식 평가(eval)의 건전성으로 이어집니다(슬9).

## 슬라이드 9: Soundness of Abstract Evaluation — Base Cases

### 원문 내용
> - eval is a sound abstraction of ceval if: ceval(γb(σ), e) ⊑ γa(eval(σ, e))
> - Prove by structural induction
> - Case e = x: ceval(γb(σ), x) = {ρ(x) | ρ∈γb(σ)} ⊑ γa(σ(x)) = γa(eval(σ,x))
> - Case e = n: ceval(γb(σ), n) ⊑ {n} ⊑ γa(sign(n)) = γa(eval(σ,n))
> - Case e = input(): ceval(γb(σ), input()) ⊑ ℤ = γa(⊤) = γa(eval(σ, input()))

### 번역
> - **`eval`(추상 식 평가)이 `ceval`(구체)의 건전한 추상**이다 ⟺ `ceval(γb(σ), e) ⊑ γa(eval(σ, e))`
> - **구조적 귀납법(structural induction)**으로 증명
> - 기저 사례: 변수 x, 상수 n, input() 각각 부등식 성립을 직접 확인

### 해설

**개념 설명 — 식 평가의 건전성을 구조적 귀납으로 ★**

추상 식 평가 `eval`의 건전성 조건:
$$ceval(\gamma_b(\sigma), e) \;\sqsubseteq\; \gamma_a(eval(\sigma, e))$$
"추상 상태를 펼쳐 구체 평가" ⊆ "추상 평가 후 펼치기". 식 `e`는 재귀 구조(변수·상수·`e1+e2`)이므로, **구조적 귀납법**으로 증명합니다 — 기저(변수·상수·input)를 직접 보이고, 합성(`e1+e2`)은 부분식의 건전성을 가정해 보임(슬10).

기저 사례:
- 변수 x: 펼친 상태들에서 x값 모음 ⊆ γ(추상 x값). σ의 정의로 성립.
- 상수 n: {n} ⊆ γ(부호 n). 자명.
- input(): ℤ ⊆ γ(⊤)=ℤ. 자명.

이것이 "작은 조각(추상 연산)의 건전성 → 식 평가의 건전성"으로 올라가는 첫 단계. 귀납 단계가 슬라이드 10.

## 슬라이드 10: Soundness of Abstract Evaluation — Inductive Case

### 원문 내용
> - Case e = e1 + e2:
> - IH: ceval(γb(σ), e1) ⊑ γa(eval(σ,e1)); ceval(γb(σ), e2) ⊑ γa(eval(σ,e2))
> - ceval(γb(σ), e1+e2)
>   ⊑ ceval(γb(σ),e1) + ceval(γb(σ),e2)
>   ⊑ γa(eval(σ,e1)) + γa(eval(σ,e2))   (IH)
>   ⊑ γa(eval(σ,e1) +̂ eval(σ,e2))   (soundness of +̂)
>   = γa(eval(σ, e1+e2))

### 번역
> 합성 사례 `e1+e2`: 귀납 가설(IH, 부분식들이 건전)과 `+̂`의 건전성(슬7)을 차례로 적용해, `ceval(γb(σ), e1+e2) ⊑ γa(eval(σ, e1+e2))`를 유도.

### 해설

**개념 설명 — 귀납 단계: 조각들을 엮어 올리기 ★**

부등식 사슬이 증명의 정수입니다:
1. 구체 덧셈은 부분식 평가의 합으로 분해.
2. **귀납 가설(IH)**: 부분식 평가가 건전 → `γa(eval(e1)) + γa(eval(e2))`로 올림.
3. **`+̂`의 건전성(슬7)**: `γa(x1)+γa(x2) ⊑ γa(x1 +̂ x2)` 적용.
4. eval 정의로 `γa(eval(e1+e2))`.

각 단계가 이미 증명한 더 작은 조각(IH, `+̂`)에 의존합니다. **"부품의 건전성이 조립품의 건전성으로 합성된다"**는 추상 해석 증명의 전형적 패턴. 같은 식으로 후속(슬11)·합류(슬12)·전이(슬13)를 차례로 증명합니다.

## 슬라이드 11: Soundness of succ

### 원문 내용
> - succ is a sound abstraction of csucc if: csucc(R, v) ⊆ succ(v)
> - Case v = if x: csucc(R, v) = T ∪ F ⊆ {true(v), false(v)} = succ(v)
> - Otherwise: csucc(R, v) = succ(v)

### 번역
> - **`succ`(분석의 후속)이 `csucc`(구체)의 건전한 추상** ⟺ `csucc(R, v) ⊆ succ(v)`
> - if 노드: 구체 후속(참/거짓 중 가능한 것)은 분석 후속(참·거짓 둘 다) ⊆ 안에 들어감
> - 그 외: 동일

### 해설

**개념 설명 — 제어 흐름의 건전성**

분석의 후속 노드 `succ`(분기에서 양쪽 다 갈 수 있다고 봄)가 구체 후속 `csucc`(상태에 따라 한쪽)를 덮음을 보입니다. `csucc(R,v) ⊆ succ(v)` — 구체가 실제로 가는 곳은 분석이 본 곳에 포함. if에서 분석은 참·거짓 양쪽을 다 후속으로 두므로(보수적), 구체가 어느 쪽으로 가든 덮음. **제어 흐름도 과근사**(가능한 분기를 다 봄)라야 건전. 합류의 건전성이 슬라이드 12.

---

## 슬라이드 12: Soundness of JOIN

### 원문 내용
> - JOIN is a sound abstraction of CJOIN if:
>   CJOIN(v)(γb(σ1),...,γb(σn)) ⊑ γb(JOIN(v)(σ1,...,σn))
> - (유도: csucc⊆succ와 γb(σw)⊑γb(⨆ σw)를 이용해 CJOIN(펼침) ⊑ γb(JOIN))

### 번역
> - **`JOIN`(분석 합류)이 `CJOIN`(구체 합류)의 건전한 추상** ⟺ `CJOIN(γb(σ1),...) ⊑ γb(JOIN(σ1,...))`
> - 후속의 건전성(슬11)과 γb 단조성을 이용해 유도

### 해설

**개념 설명**

합류 연산도 건전해야 합니다: "추상 상태들을 펼쳐 구체 합류" ⊆ "추상 합류 후 펼치기". 증명은 슬라이드 11(succ 건전)과 γb 단조성(`σw ⊑ ⨆σw`이므로 `γb(σw) ⊑ γb(⨆σw)`)을 결합. 즉 분석의 join(부호 합집합 등)이 구체 join(상태 합집합)을 덮음. 데이터플로우 합류의 건전성. 전이 함수(대입)의 건전성이 슬라이드 13.

---

## 슬라이드 13: Soundness of Constraints — Assignment Case

### 원문 내용
> - fv is a sound abstraction of cfv if: cfv(γb(σ1),...,γb(σn)) ⊑ γb(fv(σ1,...,σn))
> - v: x=e — cfv(...) = {ρ[x↦z] | ρ∈CJOIN(v)(...) ∧ z∈ceval(ρ,e)}; fv(...) = σ[x↦eval(σ,e)] where σ=JOIN(v)(...)
> - (유도 사슬: JOIN 건전 → eval 건전 → γb로 마무리)

### 번역
> - **대입 노드 전이 `fv`가 구체 전이 `cfv`의 건전한 추상** ⟺ `cfv(γb(σ⃗)) ⊑ γb(fv(σ⃗))`
> - 대입 `x=e`에 대해, JOIN 건전성(슬12)과 eval 건전성(슬9~10)을 차례로 엮어 증명

### 해설

**개념 설명 — 전이 함수의 건전성 (조각들의 총조립)**

각 노드의 전이 함수 `fv`(대입 등)가 구체 전이 `cfv`를 덮음을 보입니다. 증명 사슬은 지금까지 증명한 모든 조각을 동원:
1. CJOIN ⊑ γb(JOIN) (슬12),
2. ceval ⊑ γa(eval) (슬9~10),
을 차례로 적용해 `cfv(γb(σ⃗)) ⊑ γb(fv(σ⃗))`. 즉 **"합류·식평가가 건전하면 대입 전이도 건전"**. 부품들이 모여 한 노드 전체의 건전성이 됩니다. 진입·기타 노드가 슬라이드 14.

---

## 슬라이드 14: Soundness of Constraints — Entry and Other Nodes

### 원문 내용
> - v: entry — fv(σ1,...,σn) = ⊤
> - v: other nodes — cfv(R⃗) = CJOIN(v)(R⃗); fv(σ⃗) = JOIN(v)(σ⃗)

### 번역
> - 진입 노드: `fv = ⊤` (분석은 진입을 "아무것도 모름=⊤"으로 — 구체의 "모든 초기 상태"를 덮음)
> - 기타 노드: 전이가 곧 합류 (CJOIN/JOIN)

### 해설

**개념 설명**

나머지 노드 종류의 건전성:
- **진입**: 분석은 ⊤(모든 변수 부호 미정). 구체는 "모든 가능한 초기 상태". γ(⊤)=모든 상태이므로 덮음 → 건전.
- **기타**: 전이 = 합류뿐이라 슬12로 이미 건전.

모든 노드 종류(대입·진입·기타)의 전이가 건전함이 확립됐습니다. 이를 묶어 전체 제약 함수의 건전성이 슬라이드 15.

## 슬라이드 15: Soundness of Combined Constraints

### 원문 내용
> - cf : 𝒫(CState)^n → 𝒫(CState)^n; cf((R⃗)) = (cf1(R⃗),...,cfn(R⃗))
> - f : State^n → State^n; f((σ⃗)) = (f1(σ⃗),...,fn(σ⃗))
> - f is a sound abstraction of cf if: cf(γc(x)) ⊑ γc(f(x))
> - Implied by the soundness of each constraint

### 번역
> - 전체 제약 함수 cf(구체), f(분석)를 노드별 전이의 곱으로 묶음
> - **`f`가 `cf`의 건전한 추상** ⟺ `cf(γc(x)) ⊑ γc(f(x))`
> - 이것은 **각 노드 제약의 건전성으로부터 따라온다**

### 해설

**개념 설명 — 전이 함수 전체의 건전성**

프로그램 전체의 한 스텝 전이 함수 `f`(모든 노드 전이의 곱)가 구체 `cf`를 덮음:
$$cf(\gamma_c(x)) \;\sqsubseteq\; \gamma_c(f(x))$$
각 노드 전이가 건전(슬13~14)하므로, 그 곱인 f도 건전(곱 격자의 점별 성질, 강의 18 슬38). 이것이 **"한 스텝의 건전성"**입니다. 다음 단계: 이 한 스텝 건전성으로부터 **고정점(전체 분석) 건전성**을 끌어내는 것(슬20~22). 그림이 슬라이드 16.

---

## 슬라이드 16: Soundness of Combined Constraints (cont.)

### 원문 내용
> (가환 다이어그램) x →f→ f(x) →γc→ γc(f(x)); x →γc→ γc(x) →cf→ cf(γc(x)); 그리고 cf(γc(x)) ⊑ γc(f(x))

### 번역
> 가환 다이어그램: x를 분석 한 스텝(f) 후 구체화(γc)한 것이, x를 구체화(γc)한 뒤 구체 한 스텝(cf) 한 것을 **덮는다**(⊒).

### 해설

**개념 설명 — 한 스텝 건전성의 그림 (sound abstraction의 핵심 그림)**

이 사각형이 추상 해석 건전성의 상징적 그림입니다. 두 경로:
- **위 경로**: 분석으로 한 스텝(f) → 구체화(γc).
- **아래 경로**: 구체화(γc) → 구체로 한 스텝(cf).
"분석 후 펼치기"가 "펼친 후 진짜 실행"을 **덮으면** 그 전이는 건전(sound abstraction). 이 "사각형이 ⊑로 닫힘"이 곧 슬15의 조건. 모든 건전성 증명이 이 그림으로 환원됩니다. 일반 정의가 슬라이드 17.

## 슬라이드 17: General Definition of Soundness

### 원문 내용
> - L1, L1' (concrete lattices); L2, L2' (abstract lattices)
> - α:L1→L2, α':L1'→L2' (abstraction); γ:L2→L1, γ':L2'→L1' (concretization)
> - (α,γ) and (α',γ') form Galois connections
> - cg:L1→L1' and g:L2→L2' are monotone
> - g is a sound abstraction of cg if: cg(γ(x)) ⊑ γ'(g(x)) for every x∈L2
> - Or equivalently: α'(cg(x)) ⊑ g(α(x)) for every x∈L1

### 번역
> - 두 갈루아 연결 (α,γ), (α',γ') 사이의 함수 cg(구체), g(분석)에 대해:
> - **g가 cg의 건전한 추상** ⟺ `cg(γ(x)) ⊑ γ'(g(x))` (모든 x)
> - 동치로: `α'(cg(x)) ⊑ g(α(x))`

### 해설

**개념 설명 — 건전성의 일반 정의 (모든 조각을 한 틀로) ★**

지금까지 본 모든 조각(`+̂`, eval, succ, JOIN, fv, f)의 건전성 조건이 사실 **하나의 일반 형태**입니다:
$$cg \circ \gamma \;\sqsubseteq\; \gamma' \circ g \qquad(\text{동치: } \alpha' \circ cg \sqsubseteq g \circ \alpha)$$
"구체 함수 cg를 (입력 구체화 후) 적용한 것" ⊆ "분석 함수 g를 적용 후 구체화한 것". 입력·출력 격자가 다를 수 있어(L1→L1' 구체, L2→L2' 분석) 두 갈루아 연결을 쓰지만, 본질은 슬16의 사각형. γ 형태와 α 형태가 수반(슬4)으로 동치. 이 한 조건만 확인하면 어떤 조각이든 건전성이 판정됩니다. 인스턴스가 슬라이드 18.

---

## 슬라이드 18: General Definition of Soundness — Instances

### 원문 내용
> - +(γa²(x1,x2)) ⊑ γa(+̂(x1,x2))
> - ceval_e(γb(x)) ⊑ γa(eval_e(x))
> - CJOIN_v(γc(x⃗)) ⊑ γb(JOIN(v)(x⃗))
> - cfv(γc(x⃗)) ⊑ γb(fv(x⃗))
> - cf(γc(x⃗)) ⊑ γc(f(x⃗))

### 번역
> 슬라이드 17의 일반 조건 `cg∘γ ⊑ γ'∘g`의 다섯 인스턴스: 추상 덧셈·식 평가·합류·노드 전이·전체 전이가 모두 같은 형태로 통일됨.

### 해설

**개념 설명**

슬라이드 7~15에서 따로따로 증명한 다섯 건전성 조건이 모두 **슬라이드 17의 단일 형태**의 사례임을 한눈에 보여 줍니다. `+̂`, eval, JOIN, fv, f — 모두 "구체 함수 ∘ γ ⊑ γ ∘ 분석 함수". 이 통일이 추상 해석의 우아함: **수많은 분석 조각이 하나의 건전성 패턴**을 따릅니다. 그림이 슬라이드 19, 고정점 수준이 슬라이드 20.

---

## 슬라이드 19: General Definition of Soundness — Diagram

### 원문 내용
> (사각형 다이어그램) 𝒫(ℤ)·Sign·𝒫(CState)·State 네 격자 사이에서 ceval_e ∘ γb ⊑ γa ∘ eval_e

### 번역
> 식 평가의 건전성을 네 격자(값·부호·구체상태·추상상태) 사이 가환 사각형으로 시각화: `ceval∘γb ⊑ γa∘eval`.

### 해설

**개념 설명**

슬라이드 16의 사각형을 식 평가 버전으로 구체화한 그림. 입력 격자(State→𝒫(CState))와 출력 격자(Sign→𝒫(ℤ))가 다르므로 두 갈루아 연결(γb, γa)이 양변에. "분석 평가 후 펼치기"가 "펼친 후 구체 평가"를 덮음. 모든 조각이 이런 사각형으로 그려지고, 사각형이 ⊑로 닫히면 건전. 이제 한 스텝 건전성에서 전체(고정점) 건전성으로 도약합니다(슬20).

## 슬라이드 20: Soundness of Analysis

### 원문 내용
> - {|P|} = lfp(cf); [|P|] = lfp(f)
> - The analysis result is sound if: lfp(cf) ⊑ γ(lfp(f))
> - Or equivalently: α(lfp(cf)) ⊑ lfp(f)

### 번역
> - `{|P|}=lfp(cf)`(구체 의미), `[|P|]=lfp(f)`(분석 결과)
> - 분석이 건전 ⟺ **`lfp(cf) ⊑ γ(lfp(f))`** (동치: `α(lfp(cf)) ⊑ lfp(f)`)

### 해설

**개념 설명 — 목표: 고정점 수준의 건전성**

지금까지 증명한 건 **한 스텝(f)**의 건전성(슬15: `cf∘γ ⊑ γ∘f`). 하지만 분석 결과는 f의 **최소 고정점** `lfp(f)`이고, 진짜 의미는 cf의 `lfp(cf)`입니다. 우리가 정말 원하는 건:
$$lfp(cf) \;\sqsubseteq\; \gamma(lfp(f))$$
즉 **고정점 수준의 건전성**. 한 스텝 건전성에서 이걸 끌어내야 합니다. 그 도구가 Tarski 정리(슬21)와 건전성 정리(슬22).

---

## 슬라이드 21: Tarski's Fixpoint Theorem

### 원문 내용
> - Theorem (Tarski): If L is a complete lattice and f: L→L is monotone, then f has an lfp, given by lfp(f) = ⨅{x ∈ L | f(x) ⊑ x}
> (각주 1: A lattice-theoretical fixpoint theorem and its applications (Tarski, 1955))

### 번역
> - **Tarski 고정점 정리**: 완비 격자 L과 단조 함수 f에 대해, f는 최소 고정점을 가지며 `lfp(f) = ⨅{x | f(x) ⊑ x}` (f가 줄이는 점들, 즉 **후고정점(post-fixpoint)**들의 만남)

### 해설

**개념 설명 — Tarski 정리 (증명의 열쇠) ★**

강의 6에서 본 Tarski 정리의 핵심 형태입니다. 최소 고정점은 **후고정점들의 만남**으로 주어집니다:
$$lfp(f) = \bigsqcap\{x \mid f(x) \sqsubseteq x\}$$
- **후고정점(post-fixpoint)**: `f(x) ⊑ x`인 점(f가 더 키우지 않는 점). 모든 고정점은 후고정점.
- lfp는 그 모든 후고정점보다 작거나 같다(만남).

**왜 중요한가**: 건전성 정리(슬22)에서 "`γ(lfp(f))`가 cf의 후고정점이다(`cf(γ(lfp(f))) ⊑ γ(lfp(f))`)"를 보이면, Tarski 정리에 의해 `lfp(cf) ⊑ γ(lfp(f))`가 즉시 따라옵니다(lfp는 모든 후고정점 이하니까). 이 한 줄 논증이 고정점 건전성의 핵심. 정리가 슬라이드 22.

---

## 슬라이드 22: Soundness Theorem

### 원문 내용
> - Soundness Theorem: If L1, L2 are complete lattices with monotone functions γ:L2→L1, cf:L1→L1, f:L2→L2 such that cf∘γ ⊑ γ∘f, then lfp(cf) ⊑ γ(lfp(f))
> - 증명:
>   - cf(γ(lfp(f))) ⊑ γ(f(lfp(f))) = γ(lfp(f))
>   - γ(lfp(f)) ∈ {x | cf(x) ⊑ x}
>   - lfp(cf) ⊑ γ(lfp(f))

### 번역
> - **건전성 정리**: 단조 γ, cf, f에 대해 **한 스텝 건전성 `cf∘γ ⊑ γ∘f`**이 성립하면, **고정점 건전성 `lfp(cf) ⊑ γ(lfp(f))`**가 따라온다.
> - 증명 (3줄):
>   1. `cf(γ(lfp(f))) ⊑ γ(f(lfp(f)))` (한 스텝 건전성) `= γ(lfp(f))` (lfp(f)는 고정점이라 f(lfp(f))=lfp(f))
>   2. 따라서 `γ(lfp(f))`는 cf의 **후고정점** (`cf(x) ⊑ x`)
>   3. Tarski 정리(슬21)로 `lfp(cf) ⊑ γ(lfp(f))`

### 해설

**개념 설명 — 건전성 정리: 한 스텝 → 전체 (이 강의의 정점) ★★**

이 정리가 강의 19의 클라이맥스입니다. **"한 스텝 건전성을 증명하면 전체 분석(고정점)의 건전성이 공짜로 따라온다."**

증명은 단 세 줄, 우아합니다:
1. `cf(γ(lfp(f)))`에 한 스텝 건전성(`cf∘γ⊑γ∘f`)을 적용 → `⊑ γ(f(lfp(f)))`. 그런데 lfp(f)는 고정점이라 `f(lfp(f))=lfp(f)` → `= γ(lfp(f))`.
2. 즉 `cf(γ(lfp(f))) ⊑ γ(lfp(f))` — `γ(lfp(f))`가 cf의 **후고정점**.
3. Tarski(슬21): lfp(cf)는 모든 후고정점 이하 → `lfp(cf) ⊑ γ(lfp(f))`. ∎

**의미**: 분석 설계자는 **각 전이 함수가 한 스텝 건전함만** 증명하면 됩니다(슬7~15의 조각별 증명). 그러면 이 정리가 **자동으로 전체 분석의 건전성**을 보장합니다. 무한 반복(고정점)을 일일이 따질 필요 없이, 한 스텝만 보면 됨 — 모듈성의 극치. 증명 레시피가 슬라이드 23.

## 슬라이드 23: General Recipe for Proving Soundness

### 원문 내용
> 1. Specify the analysis (analysis lattice + constraint rules, monotone)
> 2. Specify the collecting semantics (semantic lattice + constraint rules, monotone)
> 3. Establish the connection (α: complete join morphism, or γ: complete meet morphism)
> 4. Show that each constituent of the analysis constraints is a sound abstraction of the corresponding semantic constituent
> 5. Soundness of the analysis follows from the soundness theorem

### 번역
> **건전성 증명 5단계 레시피**:
> 1. 분석 명세 (분석 격자 + 제약 규칙, 단조)
> 2. 수집 의미론 명세 (의미 격자 + 제약 규칙, 단조)
> 3. 연결 확립 (α는 완전 join 사상, 또는 γ는 완전 meet 사상 → 갈루아 연결)
> 4. 분석 제약의 **각 조각**이 대응하는 의미 조각의 건전한 추상임을 보임
> 5. **건전성 정리**로 분석 전체의 건전성이 따라옴

### 해설

**개념 설명 — 건전성 증명의 표준 절차 ★**

이 5단계가 **임의의 새 분석을 건전하게 만드는 일반 레시피**입니다:
1. 분석(추상 격자·전이) 정의 — 강의 5~17에서 한 일.
2. 구체 의미론(수집 의미론) 정의 — 강의 18.
3. α 또는 γ로 두 세계 연결, 갈루아 연결 확인(완전 join/meet 사상이면 보장, 강의 18 슬30).
4. **각 조각**(추상 연산·평가·전이)이 한 스텝 건전(`cg∘γ⊑γ∘g`)임을 증명 — 슬7~15.
5. 건전성 정리(슬22)로 전체 건전성 자동 도출.

시험에서 "이 분석의 건전성을 증명하라"가 나오면 이 레시피를 따르면 됩니다. 위드닝이 끼어도 같은 논리가 통함이 슬라이드 24.

## 슬라이드 24: Widening and Soundness

### 원문 내용
> - When widening is used, lfp(f) ⊑ [|P|]
> - {|P|} = lfp(cf) ⊑ γ(lfp(f)) ⊑ γ([|P|])
> - The same proof strategy applies

### 번역
> - 위드닝을 쓰면 분석 결과 `[|P|]`는 lfp(f)보다 **크거나 같다**(`lfp(f) ⊑ [|P|]`) — 위드닝이 위로 더 보냄
> - 그러므로 `{|P|} = lfp(cf) ⊑ γ(lfp(f)) ⊑ γ([|P|])` — **여전히 건전**
> - 같은 증명 전략이 적용된다

### 해설

**개념 설명 — 위드닝을 써도 건전한 이유**

위드닝(강의 9·16·17)은 종료를 위해 고정점보다 **위로 더 보내는**(과근사) 장치입니다. 그래서 위드닝 결과 `[|P|]`는 진짜 lfp(f)보다 크거나 같습니다(`lfp(f)⊑[|P|]`). γ가 단조이므로:
$$\{|P|\} \sqsubseteq \gamma(lfp(f)) \sqsubseteq \gamma([|P|])$$
즉 위드닝으로 더 보수적이 되어도 **건전성은 유지**(오히려 더 안전, 덜 정밀). 건전성 정리의 논리가 그대로 통합니다. **위드닝은 정밀도를 양보해 종료를 사되, 건전성은 절대 깨지 않음** — 강의 9에서 직관적으로 말한 것이 여기서 증명됩니다. 전체 요약이 슬라이드 25.

## 슬라이드 25: Summary

### 원문 내용
> - Soundness can be stated equivalently via {|P|} ⊑ γ([|P|]) or via α({|P|}) ⊑ [|P|], linked by the Galois connection
> - Analysis soundness decomposes into the soundness of its constituents (+̂, eval, JOIN, fv, f), each captured by the general condition cg∘γ ⊑ γ'∘g
> - By Tarski's theorem, soundness of the constraints lifts to soundness of the analysis: lfp(cf) ⊑ γ(lfp(f)); the same chain extends to analyses that use widening

### 번역
> - **건전성**은 `{|P|}⊑γ([|P|])`(γ형) 또는 `α({|P|})⊑[|P|]`(α형)로 동치 진술 — 갈루아 연결이 둘을 잇는다
> - **분석 건전성은 조각들의 건전성으로 분해**된다 (`+̂`·eval·JOIN·fv·f), 각 조각은 일반 조건 `cg∘γ ⊑ γ'∘g`로 포착
> - **Tarski 정리**로 제약(한 스텝)의 건전성이 분석(고정점)의 건전성으로 들어올려진다: `lfp(cf) ⊑ γ(lfp(f))`; 위드닝을 써도 같은 사슬이 적용된다

### 해설

**전체 정리 — 강의 19의 한 장 요약**

1. **건전성 정의**: `{|P|}⊑γ([|P|])` (γ형) ≡ `α({|P|})⊑[|P|]` (α형). 수반(adjunction, 슬4)으로 동치.
2. **분해**: 분석 = 여러 조각(추상 연산·식 평가·후속·합류·전이)의 조립. 각 조각이 일반 조건 `cg∘γ ⊑ γ'∘g`(한 스텝 건전)를 만족함을 구조적 귀납으로 증명.
3. **들어올리기**: 건전성 정리(`cf∘γ⊑γ∘f ⟹ lfp(cf)⊑γ(lfp(f))`)가 한 스텝 건전성을 고정점 건전성으로 승격. 증명은 "γ(lfp(f))가 cf의 후고정점" + Tarski.
4. **위드닝**: 더 보수적이라 건전성 유지.
5. **레시피**(슬23): 분석 정의 → 의미론 정의 → 갈루아 연결 → 조각별 건전성 → 정리로 마무리.

**다른 강의와의 연결 (파일 간 연결성)**

- ← **강의 18 (추상 해석 1)**: α·γ·갈루아 연결·수반이 이 강의 증명의 토대. `{|P|}=lfp(cf)`(구체 의미)도 강18에서 정의.
- ← **강의 6 (격자·고정점)**: Tarski 정리, 후고정점, 단조성이 건전성 정리의 핵심 도구.
- ← **강의 7~9 (데이터플로우·위드닝)**: succ·JOIN·전이 함수의 건전성, 위드닝의 건전성이 여기서 증명됨.
- ← **강의 5 (부호 분석)**: `+̂`·eval의 건전성이 부호 도메인 예제로.
- ← **강의 9·16·17 (위드닝)**: 위드닝이 왜 건전한지(슬24)가 모든 위드닝 사용 분석에 적용.
- → **강의 20 (추상 해석 3)**: 건전성을 넘어 **최적(best/optimal) 추상 연산**, 정밀도, 또는 추상 해석의 추가 응용으로 확장 예상.

**가장 큰 교훈**: 추상 해석의 건전성 증명은 **"분해하고 들어올리기(decompose & lift)"** 전략입니다. (1) 분석을 작은 조각으로 나눠 각 조각이 한 스텝 건전(`cg∘γ⊑γ∘g`)임을 구조적 귀납으로 보이고, (2) **건전성 정리**(Tarski 기반)로 한 스텝 건전성을 전체 고정점 건전성으로 자동 승격합니다. 이 모듈성 덕분에 설계자는 무한 반복을 걱정하지 않고 **한 스텝만 검증**하면 됩니다 — 이것이 추상 해석이 정적 분석에 준 가장 실용적인 선물입니다.

## 마치며

강의 19는 강의 18의 갈루아 연결을 무기로 **건전성을 실제로 증명하는 완결된 방법론**을 제시합니다. 핵심 한 줄: **"각 조각이 한 스텝 건전(`cf∘γ ⊑ γ∘f`)이면, 건전성 정리가 그것을 전체 분석의 건전성(`lfp(cf) ⊑ γ(lfp(f))`)으로 자동 승격한다."** 구조적 귀납으로 조각을 증명하고 Tarski 정리로 고정점을 들어올리는 이 "분해-승격" 전략은, 새 분석을 설계할 때마다 따라야 할 표준 레시피(슬23)입니다. 시험에서는 (a) 건전성의 두 동치 정의와 수반 관계(슬2·4·5), (b) 추상 연산 `+̂`의 건전성 조건과 검증(슬7~8), (c) 식 평가 건전성의 구조적 귀납 증명(슬9~10), (d) **건전성 정리의 3줄 증명**(슬22, 후고정점+Tarski), (e) 위드닝이 건전성을 깨지 않는 이유(슬24)가 단골입니다.
