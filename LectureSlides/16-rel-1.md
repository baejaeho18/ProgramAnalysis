## 강의 16 전체 조감도 (먼저 큰 그림)

지금까지 배운 분석들 — 부호(강의 5), 구간(강의 9), 포인터(강의 14~15) — 은 모두 **비관계형(non-relational)**이었습니다. 즉 **각 변수를 따로따로** 추상화했죠(x는 [1,5], y는 [0,3] 식). 이런 분석은 **변수들 사이의 관계**(예: "x와 y는 항상 같다", "z는 항상 x보다 작다")를 표현하지 못합니다.

강의 16은 **관계형 분석(relational analysis)** — 변수들 사이의 **관계를 추적**하는 분석 — 으로 나아갑니다. 핵심 도구는 두 개의 강력한 추상 도메인입니다:

1. **선형 등식 도메인(Linear Equalities, Karr 1976)** — 슬라이드 6~28. `x = y`, `2x - y = 0` 같은 **등식들의 연립**으로 상태를 표현. 기하적으로는 점·직선·평면 같은 **아핀 부분공간(affine subspace)**.
2. **선형 부등식 도메인(Linear Inequalities / Polyhedra, Cousot–Halbwachs 1978)** — 슬라이드 29~44. `x ≤ 5`, `z < x` 같은 **부등식들의 연립**으로 표현. 기하적으로는 **볼록 다면체(convex polyhedron)**. 구간·등식 도메인을 모두 포함하는 가장 표현력 강한 도메인.

각 도메인마다 **표현 방식(행렬·기하)**, **순서(⊆)**, **join(⊔)**, **위드닝**, **조건 분기(control-sensitivity)**, **대입(가역·비가역)**을 차례로 정의합니다. 이는 강의 5~9에서 배운 "추상 도메인을 설계하는 절차"(격자 구조 + 전이 함수 + 위드닝)를 가장 정교한 도메인에 적용하는 종합 실습입니다.

선형대수(행렬·벡터·아핀공간)가 많이 등장하지만, 기하적 직관(점/선/면)으로 따라가면 어렵지 않습니다.

## 슬라이드 2: Non-Relational Analysis

### 원문 내용
> - Tracks each variable separately
> - Ignores relationships between variables
> ```
> x = input();
> // x: [-inf, inf]
> y = x;
> // x: [-inf, inf], y: [-inf, inf]
> z = x == y;
> // x: [-inf, inf], y: [-inf, inf], z: [0, 1]
> ```
> - Does not know that x == y, so z can be either 0 or 1

### 번역
> - **비관계형 분석**: 각 변수를 따로 추적, 변수 간 관계는 무시
> - 코드: x는 임의 정수, y=x, z=(x==y). 비관계형 분석은 x,y가 각각 [-∞,∞]라고만 알고 **둘이 같다는 사실을 모름** → z가 0 또는 1 [0,1].

### 해설

**개념 설명 — 비관계형의 한계**

비관계형 분석은 각 변수를 독립된 구간으로 봅니다. `y=x` 후에도 "x∈[-∞,∞], y∈[-∞,∞]"라고만 알 뿐, **x와 y가 같은 값**이라는 관계를 잃어버립니다. 그래서 `z = (x==y)`를 평가할 때 "x와 y가 다를 수도 있다"고 보아 z∈{0,1}로 둡니다 — 실제로는 x==y가 항상 참이라 z=1인데도요.

이 정보 손실이 비관계형 분석의 근본 약점입니다. 슬라이드 3이 관계형 분석의 답을 보여 줍니다.

## 슬라이드 3: Relational Analysis

### 원문 내용
> - Tracks relationships between variables
> ```
> x = input();
> y = x;
> // x = y
> z = x == y;
> // x = y, z = 1
> ```
> - Knows that x == y, so z is always 1

### 번역
> - **관계형 분석**: 변수 간 관계를 추적
> - 코드: `y=x` 후 상태가 **`x = y`**(둘이 같다는 관계). 그러므로 `z=(x==y)`는 **항상 1**.

### 해설

**개념 설명 — 관계를 기억한다**

관계형 분석은 상태를 "x=[..], y=[..]"가 아니라 **변수들 사이의 관계식** "x = y"로 표현합니다. `y=x` 대입이 "x와 y는 같다"는 등식을 만들고, 이를 기억하므로 `x==y`가 항상 참 → z=1로 정확히 판단합니다. 비관계형이 못 하던 추론을 해냅니다. 이 "관계를 기억하는 능력"이 어디에 쓸모 있는지가 슬라이드 4~5의 동기입니다.

## 슬라이드 4: Motivation 1: Dynamically Sized Arrays

### 원문 내용
> ```
> x = input();
> y = [0; x];
> if z < x {
>   y[z] = 1;
> }
> ```
> - We need to know that z < x to ensure that z is a valid index

### 번역
> 코드: 크기가 `x`인 배열 `y`를 만들고, `z < x`일 때만 `y[z]`에 접근.
> - `z`가 유효한 인덱스임을 보장하려면 **`z < x`라는 관계**를 알아야 한다

### 해설

**개념 설명 — 배열 경계 검사**

동적 크기 배열 `y`의 길이는 `x`입니다. `y[z]` 접근이 안전하려면 `0 ≤ z < x`여야 합니다. `if z < x` 안에서는 이 조건이 보장되는데, 이를 분석이 알려면 **z와 x의 관계(`z < x`)**를 추적해야 합니다 — 비관계형(z, x 각각 구간)으로는 불가능. 관계형 부등식 도메인(슬라이드 29~)이 정확히 이런 `z < x`를 다룹니다. 배열 경계 오류 검출(보안·안전)의 핵심 응용.

## 슬라이드 5: Motivation 2: Binary Analysis

### 원문 내용
> ```
> x = sp - 4;
> *x = 0;
>
> y = sp - 4;
> z = *y;
> ```
> - Local variables are accessed relatively to the stack pointer (sp)
> - We need to identify addresses relative to sp to track the values of local variables

### 번역
> 코드: 지역 변수는 스택 포인터 `sp`로부터의 상대 주소로 접근됨. `x=sp-4`에 0을 쓰고, `y=sp-4`를 읽으면 같은 위치.
> - 지역 변수 값을 추적하려면 **sp 기준 상대 주소**(`x = sp-4`, `y = sp-4` → x = y)를 식별해야 한다

### 해설

**개념 설명 — 바이너리(어셈블리) 분석**

컴파일된 바이너리에서는 지역 변수가 `sp - 4` 같은 **스택 포인터 상대 주소**로 접근됩니다. `x = sp-4`와 `y = sp-4`가 같은 주소(`x = y`)임을 알아야, `*x=0` 후 `*y`를 읽으면 0임을 추론할 수 있습니다. 이 역시 변수 간 관계(`x = y`, 또는 `x = sp - 4`)를 추적하는 관계형 분석이 필요합니다 — 등식 도메인(슬라이드 6~)의 응용. 디컴파일·바이너리 보안 분석의 토대.

**슬라이드 연결**: 이제 첫 번째 관계형 도메인 — 선형 등식 — 의 정의가 슬라이드 6.

## 슬라이드 6: Abstract Domain of Linear Equalities

### 원문 내용
> - Var = {xi | i ∈ I}
> - State = {⊥} ∪ {⋀_{i∈I} (bi = ∑_{j∈I} a_{i,j} xj)}
> - If the program has n variables, use n linear equalities
> - An equality can be ignored if its every coefficient is 0
>   - Effectively, we have at most n equalities
>
> (각주 1: Affine relationships among variables of a program (Karr, 1976))

### 번역
> - 변수 집합 Var = {xi}
> - **상태** = ⊥(불가능) 또는 **선형 등식들의 연립** `⋀ (bi = ∑ a_{i,j} xj)`
> - 프로그램에 변수가 n개면, **n개의 선형 등식**을 사용
> - 모든 계수가 0인 등식은 무시 가능 → 사실상 **최대 n개**의 등식
> - (각주: Karr 1976, "프로그램 변수 간 아핀 관계")

### 해설

**개념 설명 — 선형 등식의 연립으로 상태를 표현**

이 도메인의 추상 상태는 **선형 등식들의 모음(연립방정식)**입니다. 예: `x = y`(즉 `x - y = 0`), `2x + 3y = 7` 등. 각 등식은 `상수 = 계수들의 선형결합` 꼴.

- 변수 n개면 등식도 최대 n개로 충분합니다(선형대수: n차원 공간에서 독립인 선형 등식은 최대 n개).
- 계수가 모두 0인 등식(0=0)은 정보 없음이라 무시.
- **⊥**: 모순된 상태(해가 없음, 도달 불가능한 지점).

이것이 **Karr의 도메인**(1976)입니다. "아핀 관계(affine relationship)"는 선형 등식 관계를 뜻합니다. 기하적 직관이 슬라이드 7~9.

**각주**: Karr(1976)가 처음 제안. 선형 등식 분석의 고전.

**슬라이드 연결**: 2차원·3차원에서 이 등식들이 무엇을 뜻하는지 기하적으로 봅니다(슬라이드 7~9).

## 슬라이드 7: 2-Dimensional Linear Equalities

### 원문 내용
> - Var = {x, y}
> - State = {⊥} ∪ {⊤} ∪ {b1 = a_{1,1}x + a_{1,2}y} ∪ {b1 = a_{1,1}x + a_{1,2}y ∧ b2 = a_{2,1}x + a_{2,2}y}
> - No equalities: plane
> - One equality: line
> - Two equalities: point
> - (예: x + 2y = 1; x + 2y = 1 ∧ x − y = 4 → 점 (3, -1))

### 번역
> - 변수 {x, y}일 때 상태는: ⊥, ⊤(등식 없음), 등식 1개, 등식 2개 중 하나
> - **등식 0개**: 평면 전체 (아무 제약 없음)
> - **등식 1개**: 직선 (예: x+2y=1)
> - **등식 2개**: 점 (예: x+2y=1 ∧ x−y=4 → (3,−1))

### 해설

**개념 설명 — 등식 개수 = 차원 감소**

2변수(x,y)는 평면(2차원)에 대응합니다. 선형 등식 하나하나가 **자유도를 1씩 줄입니다**:
- 등식 0개(⊤): 평면 전체 — x,y가 무엇이든 가능.
- 등식 1개: 직선 — 그 등식을 만족하는 점들(예: x+2y=1은 한 직선).
- 등식 2개: 점 — 두 직선의 교점(예: (3,−1)). 더 이상 자유도 없음.
- (모순된 등식이면 ⊥ — 해가 없음.)

이 "등식 = 초평면(hyperplane), 연립 = 그 교집합(아핀 부분공간)"이라는 기하적 그림이 이 도메인의 핵심 직관입니다. 슬라이드 8이 3차원으로 확장.

## 슬라이드 8: 3-Dimensional Linear Equalities — Definition

### 원문 내용
> - Var = {x, y, z}
> - State = {⊥} ∪ {⊤} ∪ {등식 1개} ∪ {등식 2개} ∪ {등식 3개}
> - No equalities: space
> - One equality: plane
> - Two equalities: line
> - Three equalities: point

### 번역
> - 변수 {x,y,z}(3차원 공간)일 때:
>   - **등식 0개**: 공간 전체
>   - **등식 1개**: 평면
>   - **등식 2개**: 직선 (두 평면의 교선)
>   - **등식 3개**: 점 (세 평면의 교점)

### 해설

**개념 설명**

3변수는 3차원 공간. 등식 하나가 차원을 1씩 줄입니다: 공간(3D)→평면(2D)→직선(1D)→점(0D). 슬라이드 7의 2차원 패턴이 그대로 한 차원 올라간 것. n변수면 등식 k개가 (n−k)차원 아핀 부분공간을 나타냅니다. 일반화된 직관이 잡힙니다.

**슬라이드 연결**: 구체 예가 슬라이드 9.

---

## 슬라이드 9: 3-Dimensional Linear Equalities — Example

### 원문 내용
> - y + z = 0  (평면)
> - y + z = 0 ∧ y − z = 2  (직선)
> - y + z = 0 ∧ y − z = 2 ∧ x = 1  (점)

### 번역
> - `y+z=0`: 평면 하나
> - `y+z=0 ∧ y−z=2`: 두 평면의 교선(직선). 이로부터 y=1, z=−1이 정해지고 x는 자유.
> - `... ∧ x=1`: x까지 고정되어 점 (1, 1, −1).

### 해설

**개념 설명**

슬라이드 8의 추상 정의를 구체 등식으로 확인. `y+z=0`(평면) → `∧ y−z=2`를 더하면 y,z가 정해져 직선(x 자유) → `∧ x=1`로 점. 등식을 더할수록 해집합이 좁아지는 과정을 시각화. 이제 이 상태를 컴퓨터가 다루려면 표현 방식이 필요 — 슬라이드 10(행렬)·13(기하).

## 슬라이드 10: State Representation: Matrix

### 원문 내용
> - Matrix representation: AX = B
>   - where X is a vector made of the program variables

### 번역
> - **행렬 표현**: `AX = B`
>   - X는 프로그램 변수들로 이루어진 벡터

### 해설

**개념 설명 — 연립 선형 등식 = 행렬 방정식**

여러 선형 등식의 연립은 선형대수의 **행렬 방정식 `AX = B`**로 깔끔히 표현됩니다. X는 변수 벡터(예: (x,y)ᵀ), A는 계수 행렬, B는 상수 벡터. 각 행이 하나의 등식. 이렇게 하면 등식 조작이 **행렬 연산**(가우스 소거 등)으로 기계화됩니다. 슬라이드 11~12가 예시.

## 슬라이드 11: Matrix Representation: 2-Dimensional Examples

### 원문 내용
> - x + 2y = 1: (1 2)(x y)ᵀ = 1
> - x + 2y = 1 ∧ x − y = 4: [[1,2],[1,−1]](x y)ᵀ = (1 4)ᵀ

### 번역
> - 등식 1개 `x+2y=1`: 1×2 행렬 `(1 2)`로 `(1 2)(x,y)ᵀ = 1`.
> - 등식 2개: 2×2 행렬 `[[1,2],[1,−1]]`로 `[[1,2],[1,−1]](x,y)ᵀ = (1,4)ᵀ`.

### 해설
선형 등식을 행렬로 옮기는 직역. 각 등식이 행렬의 한 행, 우변이 B의 한 성분. 등식 1개는 1행, 2개는 2행. 슬라이드 7의 직선·점이 행렬 형태로 표현됨. 3차원판은 슬라이드 12.

## 슬라이드 12: Matrix Representation: 3-Dimensional Examples

### 원문 내용
> - y + z = 0: (0 1 1)(x y z)ᵀ = 0
> - y + z = 0 ∧ y − z = 2: [[0,1,1],[0,1,−1]](x y z)ᵀ = (0 2)ᵀ
> - ... ∧ x = 1: [[0,1,1],[0,1,−1],[1,0,0]](x y z)ᵀ = (0 2 1)ᵀ

### 번역
> 슬라이드 9의 등식들을 행렬로. 등식 1·2·3개가 각각 1·2·3행 행렬.

### 해설
3변수 등식들의 행렬 표현. 슬라이드 9(평면→직선→점)의 행렬판. `x=1`은 `(1 0 0)(x,y,z)ᵀ=1`. 행이 늘수록 해공간이 좁아짐. 행렬 표현은 계산에 편하지만, **join** 등엔 다른(기하) 표현이 유용 — 슬라이드 13.

## 슬라이드 13: State Representation: Geometric

### 원문 내용
> - A point P and a generating vector basis U0, ..., Um
>   - where P + ∑_{i=0}^m μi Ui constitute the set of solutions

### 번역
> - **기하 표현**: 한 점 `P`와 **생성 벡터 기저(generating vector basis)** `U0,...,Um`
>   - 해집합 = `{ P + ∑ μi Ui | μi ∈ ℝ }` (P에서 출발해 Ui 방향들로 자유롭게 이동한 모든 점)

### 해설

**개념 설명 — 아핀 부분공간을 점+방향으로**

행렬 표현(`AX=B`)이 "**제약**으로 해집합을 정의"한다면, 기하 표현은 "**해집합을 직접 생성**"합니다. 한 점 P(해집합 위의 한 점)와 방향 벡터들 Ui로, `P + (방향들의 임의 결합)`이 곧 해집합.

예: 직선이면 P(직선 위 한 점) + U0(직선 방향) 하나. 평면이면 P + 두 방향. 점이면 P만(방향 없음). 이 **점+생성벡터** 표현은 join을 계산할 때 특히 편리합니다(슬라이드 19). 행렬(제약 기반)과 기하(생성 기반)는 **이중적(dual)** 관계 — 같은 아핀공간의 두 표현법.

**슬라이드 연결**: 기하 표현의 예가 슬라이드 14~15.

## 슬라이드 14: Geometric Representation: 2-Dimensional Examples

### 원문 내용
> - x + 2y = 1: P = (1, 0), U0 = (−2, 1)
> - x + 2y = 1 ∧ x − y = 4: P = (3, −1)

### 번역
> - 직선 `x+2y=1`: 점 P=(1,0)(직선 위 한 점)과 방향 U0=(−2,1)(직선을 따라가는 방향). 즉 (1,0)+μ(−2,1)이 전체 직선.
> - 점 (교점): P=(3,−1)만, 방향 없음(자유도 0).

### 해설

**개념 설명**

`x+2y=1` 직선: (1,0)은 이 직선 위 점(1+0=1 ✓). U0=(−2,1)은 방향 — (1,0)에서 (−2,1) 방향으로 가도 등식 유지(−2+2=0, 변화 0 ✓). 그래서 (1,0)+μ(−2,1) = (1−2μ, μ)가 직선 전체. 등식 2개(점)면 방향이 없어 P 하나로 끝. 슬라이드 7·14를 비교하면 같은 직선/점의 제약 표현(슬7) vs 생성 표현(슬14)을 볼 수 있습니다.

## 슬라이드 15: Geometric Representation: 3-Dimensional Examples

### 원문 내용
> - y + z = 0: P = (0,0,0), U0 = (1,0,0), U1 = (0,1,−1)
> - y + z = 0 ∧ y − z = 2: P = (0,1,−1), U0 = (1,0,0)
> - ... ∧ x = 1: P = (1,1,−1)

### 번역
> - 평면 `y+z=0`: P=(0,0,0)과 두 방향 U0=(1,0,0)(x 방향), U1=(0,1,−1)(평면 내 방향).
> - 직선: P=(0,1,−1)과 한 방향 U0=(1,0,0).
> - 점: P=(1,1,−1)만.

### 해설
3차원판 기하 표현. 평면은 방향 2개, 직선은 1개, 점은 0개 — 방향 개수 = 부분공간 차원. 슬라이드 9(제약)와 15(생성)가 같은 평면/직선/점의 두 표현. 이제 이 표현들로 격자 연산을 정의합니다: 순서(슬16), join(슬19).

## 슬라이드 16: Order

### 원문 내용
> - s1 ⊆ s2 if and only if the solution set of s1 is a subset of the solution set of s2
> - Where s1 is represented by P, U0, ..., Um and s2 is represented by A' and B', check if A'P = B' and A'Ui = 0 for all i

### 번역
> - **순서 s1 ⊆ s2**: s1의 해집합이 s2의 해집합의 부분집합일 때 (s1이 더 좁고 구체적)
> - s1을 기하 표현(P, U0,...,Um)으로, s2를 행렬 표현(A', B')으로 둘 때: **A'P = B'** (s1의 점이 s2의 등식을 만족)이고 **모든 i에 대해 A'Ui = 0** (s1의 모든 방향이 s2의 등식을 유지)인지 확인

### 해설

**개념 설명 — 포함 관계 판정 (격자 순서)**

격자의 순서 ⊆는 "해집합의 포함"입니다. s1 ⊆ s2는 "s1이 더 많은 등식을 가진(더 좁은) 상태". 판정법이 기발합니다 — s1은 생성 표현(점+방향), s2는 제약 표현(행렬):
- **A'P = B'**: s1의 대표점 P가 s2의 모든 등식을 만족 → s1의 출발점이 s2 안에 있음.
- **A'Ui = 0**: s1의 각 방향 Ui로 움직여도 s2의 등식이 깨지지 않음(변화량 0) → s1이 뻗는 모든 방향도 s2 안에 머묾.

둘 다 참이면 s1의 모든 점(P + 방향 결합)이 s2를 만족 → s1 ⊆ s2. **생성 표현과 제약 표현의 이중성**을 활용한 우아한 판정. 슬라이드 17~18이 예.

## 슬라이드 17: Order — Example 1

### 원문 내용
> - s1: y + z = 0 ∧ y − z = 2 → P = (0,1,−1), U0 = (1,0,0)
> - s2: y + z = 0 → A' = (0 1 1), B' = 0
> - A'P = (0 1 1)(0,1,−1)ᵀ = 0 = B' ✓
> - A'U0 = (0 1 1)(1,0,0)ᵀ = 0 ✓

### 번역
> s1(직선, 더 좁음)이 s2(평면, 더 넓음)에 포함되는지: P가 s2 등식 만족(A'P=0=B' ✓), 방향 U0도 등식 유지(A'U0=0 ✓) → **s1 ⊆ s2** 확인.

### 해설
직선 s1이 평면 s2 안에 있음을 슬라이드 16 판정법으로 확인. P=(0,1,−1)이 y+z=0 만족, 방향 (1,0,0)으로 가도 y+z 불변 → 직선 전체가 평면 위. 직관(직선이 평면에 놓임)과 일치. 슬라이드 18은 포함이 안 되는 경우.

## 슬라이드 18: Order — Example 2

### 원문 내용
> - s1: y + z = 2 ∧ y − z = 2 → P = (0,2,0), U0 = (1,0,0)
> - s2: y + z = 0 → A' = (0 1 1), B' = 0
> - A'P = (0 1 1)(0,2,0)ᵀ = 2 ≠ B'

### 번역
> s1(직선)이 s2(평면)에 포함되는지: P=(0,2,0)을 s2 등식에 넣으면 A'P=2 ≠ 0=B' → **포함 안 됨**(s1 ⊄ s2).

### 해설
이번 s1의 직선은 y+z=2 위에 있어, y+z=0 평면과 평행하지만 떨어져 있습니다. P가 s2 등식을 위반(2≠0)하므로 포함 실패. 슬라이드 17(포함)과 18(불포함)이 판정법의 양면. 이제 두 상태를 합치는 join이 슬라이드 19.

## 슬라이드 19: Join

### 원문 내용
> - Where s1 is represented by P, U0, ..., Um and s2 is represented by P', U'0, ..., U'n, use P as the point and normalize P'−P, U0, ..., Um, U'0, ..., U'n for the generating vector basis

### 번역
> - **join(s1 ⊔ s2)**: s1을 (P, U0..Um), s2를 (P', U'0..U'n) 기하 표현으로 둘 때:
>   - **점**으로 P를 사용
>   - **생성 벡터 기저**로 `P'−P, U0,...,Um, U'0,...,U'n`을 모아 **정규화(normalize, 중복·종속 제거)**

### 해설

**개념 설명 — 두 아핀공간을 포함하는 최소 공간 (기하 표현의 진가)**

join은 격자에서 **두 상태를 모두 포함하는 가장 작은 상태**(최소 상계, 강의 5~6)입니다. 기하적으로는 "s1과 s2를 둘 다 포함하는 가장 작은 아핀공간"입니다.

비결은 **생성 표현으로 합치기**:
- 한쪽 점 P를 기준점으로 삼고,
- s1의 방향들(Ui), s2의 방향들(U'j), 그리고 **두 점을 잇는 방향 `P'−P`**까지 모두 방향 기저로 모음.
- 종속된(중복) 벡터를 정규화로 제거.

`P'−P`를 넣는 이유: s1과 s2가 떨어져 있으면 그 둘을 잇는 방향도 결과 공간에 있어야 둘을 모두 포함하니까요. 이렇게 **방향을 합집합**하면 두 공간을 아우르는 최소 공간이 나옵니다(제약 표현으론 어려운 일이 생성 표현으론 자연스러움). 슬라이드 20이 예.

## 슬라이드 20: Join — Example

### 원문 내용
> - s1: y+z=0 ∧ y−z=2 → P=(0,1,−1), U0=(1,0,0)
> - s2: y+z=2 ∧ y−z=0 → P'=(0,1,1), U'0=(1,0,0)
> - P''=(0,1,−1), P'−P=(0,0,2), U0=(1,0,0), U'0=(1,0,0) ⇒ U''0=(1,0,0), U''1=(0,0,1)
> - s1 ⊔ s2: y = 1

### 번역
> 두 평행 직선 s1, s2(둘 다 y=1 평면 위, 방향 x). join: 점 P=(0,1,−1), 방향으로 U0=(1,0,0)과 P'−P=(0,0,2)→정규화하면 (0,0,1). 두 방향 (1,0,0),(0,0,1)이 x,z 방향 → 결과는 **평면 y=1**.

### 해설

**개념 설명**

s1, s2는 모두 y=1을 만족하는(하지만 z가 다른) 평행한 두 직선입니다. 이들을 모두 포함하는 최소 공간은 **y=1 평면**(x,z 자유, y만 1로 고정). join 절차가 이를 정확히 계산: 방향 U0=(1,0,0)(x방향)과 P'−P를 정규화한 (0,0,1)(z방향)을 합쳐 x,z 두 방향 → y만 고정된 평면 y=1. 두 직선의 공통 등식(y=1)만 남고, 차이 나던 등식(z 관련)은 버려짐 — join이 **공통 정보만 유지**함을 보여 줍니다. 다음은 위드닝(슬21).

## 슬라이드 21: Widening

### 원문 내용
> - The lattice has a finite height of |Var| + 1
> (격자: 등식 0개 — 1개 — ... — |Var|개 — ⊥)
> - Just use the join operator as a widening operator

### 번역
> - 이 격자의 **높이는 유한**(|Var|+1): 등식 0개(⊤) → 1개 → ... → |Var|개 → ⊥
> - 따라서 **위드닝이 필요 없이 join을 그대로** 위드닝으로 써도 종료된다

### 해설

**개념 설명 — 유한 높이라 위드닝 불필요**

위드닝(강의 9)은 무한 높이 격자에서 종료를 보장하려고 도입했습니다. 그런데 **선형 등식 격자는 높이가 유한**합니다: 등식 개수가 0(⊤)에서 |Var|개(점)까지, 그리고 ⊥. 한 변수당 등식 하나씩 줄거나 늘 수 있으니 사슬 길이가 최대 |Var|+1.

join을 반복하면 등식 개수가 **단조 감소**(정보가 줄어듦)하다가 유한 단계에서 멈춥니다. 그래서 별도 위드닝 없이 **join 자체를 위드닝으로** 써도 고정점에 도달합니다. 등식 도메인의 큰 장점(부등식 도메인은 무한 높이라 진짜 위드닝 필요 — 슬라이드 38). 다음은 분기 처리(슬22).

## 슬라이드 22: Control-Sensitivity

### 원문 내용
> - If a condition is defined by a linear equality, we add the equality to the state and normalize it
> - If a condition is defined by a linear inequality, we cannot add a new equality but may produce ⊥ if it is unsatisfiable

### 번역
> - 조건이 **선형 등식**이면, 그 등식을 상태에 **추가**하고 정규화한다
> - 조건이 **선형 부등식**이면, 새 등식을 더할 순 없지만, 현재 상태와 **모순이면 ⊥** 산출

### 해설

**개념 설명 — 분기 조건 활용 (control-sensitivity)**

`if` 조건이 참인 가지에선 그 조건을 상태에 반영해 정밀도를 높입니다(강의 9의 filter와 같은 역할):
- 조건이 **등식**(`x==y` 등)이면 → 그 등식을 상태에 추가(해공간이 좁아짐).
- 조건이 **부등식**(`x<y` 등)이면 → 등식 도메인은 부등식을 **표현 못 함**(한계!). 다만 그 부등식이 현재 등식들과 **모순이면 ⊥**(그 가지는 도달 불가)로 처리. 모순 아니면 정보 추가 없이 통과.

이 "부등식을 못 다룸"이 등식 도메인의 표현력 한계이고, 슬라이드 29의 **부등식 도메인**이 나오는 이유입니다. 예가 슬라이드 23.

## 슬라이드 23: Control-Sensitivity — Example

### 원문 내용
> Current state: x + 2y = 1
> - Condition: 2x + 4y = 2 ⇒ x + 2y = 1
> - Condition: x − y = 4 ⇒ x = 3 ∧ y = −1
> - Condition: x + 2y = 2 ⇒ ⊥

### 번역
> 현재 상태 `x+2y=1`에 조건을 추가:
> - `2x+4y=2`: `x+2y=1`과 동치(같은 정보) → 변화 없음.
> - `x−y=4`: 새 등식 추가 → 연립 풀면 x=3, y=−1(점).
> - `x+2y=2`: 기존 `x+2y=1`과 **모순** → ⊥(도달 불가).

### 해설

**개념 설명**

세 가지 조건 추가의 결과:
- 동치 조건(2x+4y=2 = 2배): 새 정보 없음, 상태 유지.
- 독립 조건(x−y=4): 등식 2개가 되어 점으로 좁혀짐(x=3,y=−1).
- 모순 조건(x+2y=2): x+2y가 1이자 2일 수 없음 → ⊥. 이 분기는 절대 실행 안 됨(예: `if x+2y==2`인데 상태가 x+2y=1이면 그 가지는 죽은 코드).

조건이 상태를 어떻게 좁히는지(또는 죽이는지)를 보여 줍니다. 다음은 대입 처리 — 가역(슬24)·비가역(슬26).

## 슬라이드 24: Assignments (Invertible)

### 원문 내용
> - x_o = b + ∑_{i∈I} ai xi where a_o ≠ 0
>   - x_o^new = b + a_o x_o^old + ∑_{i∈I\{o}} ai xi
>   - x_o^old = (1/a_o)(x_o^new − b − ∑_{i∈I\{o}} ai xi)
> - Update the state by substituting x_o with (1/a_o)(x_o − b − ∑_{i∈I\{o}} ai xi)

### 번역
> - **가역 대입** `x_o = b + ∑ ai xi`인데 **자기 계수 a_o ≠ 0** (우변에 자기 자신 x_o가 0 아닌 계수로 등장):
>   - 새 값을 옛 값으로 풀 수 있음: `x_o^old = (1/a_o)(x_o^new − b − ∑_{i≠o} ai xi)`
>   - 상태의 모든 등식에서 **옛 x_o를 이 식으로 치환**

### 해설

**개념 설명 — 가역 대입: 옛 값을 복원해 치환**

대입 `x = ...`은 x의 옛 값을 새 값으로 바꿉니다. 상태(등식들)는 옛 x로 쓰여 있으니, 새 x로 다시 써야 합니다. **가역(invertible)**이란 대입식에서 **옛 x를 새 x로 표현할 수 있는** 경우 — 우변에 x 자신이 0 아닌 계수로 있을 때(예: `x = x+1`).

이때 옛 x를 새 x의 식으로 풀어내(역산), 상태의 모든 등식에서 옛 x를 그 식으로 치환합니다. 정보 손실 없음(가역이니까). 예가 슬라이드 25.

## 슬라이드 25: Invertible Assignment — Example

### 원문 내용
> - Current state: x + y = 1
> - Assignment: x = x + 1;
> - Updated state: x + y = 2

### 번역
> 상태 `x+y=1`에서 `x = x+1` 대입. 옛 x = 새 x − 1. 상태의 옛 x를 (x−1)로 치환: (x−1)+y=1 → **x+y=2**.

### 해설

**개념 설명**

`x=x+1`은 가역(우변에 x 있음). 옛 x = 새 x − 1. 상태 `(옛x)+y=1`에 대입 → `(x−1)+y=1` → `x+y=2`. 직관적으로도 x가 1 늘었으니 x+y도 1 늘어 2. 관계가 정확히 유지·갱신됩니다. 비가역은 슬라이드 26.

## 슬라이드 26: Assignments (Non-Invertible)

### 원문 내용
> - x_o = b + ∑_{i∈I} ai xi where a_o = 0
> - Normalize the basis so that nonzero coefficient for x_o occurs in at most one equality
> - Drop the equality with nonzero coefficient for x_o
> - Add the new equality x_o = b + ∑_{i∈I} ai xi

### 번역
> - **비가역 대입** `x_o = b + ∑ ai xi`인데 **자기 계수 a_o = 0** (우변에 자기 자신 없음, 예: `x = y − z`):
>   1. x_o의 0 아닌 계수가 **최대 한 등식**에만 나오도록 정규화
>   2. x_o를 포함한 그 등식을 **버림**(옛 x 정보 폐기 — 복원 불가하니까)
>   3. 새 등식 `x_o = b + ∑ ai xi`를 추가

### 해설

**개념 설명 — 비가역 대입: 옛 정보 버리고 새 등식 추가**

**비가역(non-invertible)**은 대입식에 x 자신이 없어(`x = y−z` 등) **옛 x를 복원할 수 없는** 경우입니다. 옛 x 값은 영영 사라지므로(덮어쓰기), 옛 x에 관한 정보를 **버려야** 합니다:
1. 가우스 소거로 x_o를 한 등식에만 모음.
2. 그 등식(옛 x 관련)을 삭제 — 옛 x의 관계는 더 이상 유효하지 않으니.
3. 새 관계 `x = y−z`를 등식으로 추가.

가역 대입(정보 보존)과 달리 일부 정보(옛 x의 옛 관계)를 잃습니다. 예가 슬라이드 27.

## 슬라이드 27: Non-Invertible Assignment — Example

### 원문 내용
> - Current state: x + y = 0 ∧ x + z = 0
> - Assignment: x = y − z;
> - Normalized: x + y = 0 ∧ y − z = 0
> - Updated state: x − y + z = 0 ∧ y − z = 0 (or x = 0 ∧ y − z = 0)

### 번역
> 상태 `x+y=0 ∧ x+z=0`에서 `x = y−z`(비가역). 먼저 x를 한 등식에만 두도록 정규화(두 등식을 빼서 `y−z=0` 얻음): `x+y=0 ∧ y−z=0`. x 포함 등식(x+y=0)을 버리고 새 등식 x=y−z 추가 → `x−y+z=0 ∧ y−z=0`, 즉 (y=z이므로) `x=0 ∧ y−z=0`.

### 해설

**개념 설명**

`x=y−z`는 비가역. 절차대로: 정규화로 x 없는 등식 `y−z=0`을 분리 → x 포함 옛 등식 버림 → 새 등식 x=y−z 추가. 결과 `x−y+z=0 ∧ y−z=0`. y=z이므로 x=y−z=0 → `x=0`. 옛 x의 관계(x+y=0 등)는 사라지고, 새 x의 관계가 정확히 반영됨. 이제 모든 연산이 갖춰졌으니 전체 예제(슬28).

## 슬라이드 28: Putting It Together

### 원문 내용
> ```
> x = 1
> // x = 1
> if ... {
>   y = 2;
>   // x = 1, y = 2
> } else {
>   y = 4;
>   // x = 1, y = 4
>   x = x + 1;
>   // x = 2, y = 4
> }
> // 2x - y = 0
> if x + 2 == y {
>   // x = 2, y = 4
> } else {
>   // 2x - y = 0
> }
> ```

### 번역
> 전체 분석 예: 분기에서 (x=1,y=2)와 (x=2,y=4)가 합류 → join. 두 상태의 공통 등식은 **2x−y=0**(2·1−2=0, 2·2−4=0 둘 다 만족). 이후 `if x+2==y`는 등식 추가로 (x=2,y=4)로 좁혀지고, else는 2x−y=0 유지.

### 해설

**개념 설명 — 모든 조각의 결합**

이 예제가 등식 도메인의 전 과정을 보여 줍니다:
- 대입(x=1, y=2/4, x=x+1)으로 등식 갱신.
- 분기 합류에서 **join**: (x=1,y=2)와 (x=2,y=4)의 공통 관계를 찾으면 **2x−y=0**(개별 값 x,y는 다르지만 그 *관계*는 공통!). 비관계형이라면 x∈[1,2], y∈[2,4]로 관계를 잃었을 텐데, 관계형은 2x−y=0을 보존.
- 조건 분기(control-sensitivity)로 then 가지는 점으로 좁힘.

**핵심**: join이 개별 값은 뭉개도 **변수 간 관계(2x−y=0)는 정확히 유지**한다는 것 — 관계형 분석의 위력. 여기까지 등식 도메인. 슬라이드 29부터 더 강력한 **부등식 도메인**.

**슬라이드 연결**: 등식으론 못 했던 부등식(z<x 등)을 다루는 도메인이 슬라이드 29.

## 슬라이드 29: Abstract Domain of Linear Inequalities

### 원문 내용
> - Var = {xi | i ∈ I}
> - State = {⊥} ∪ {⋀_i (∑_{j∈I} a_{i,j} xj ≤ bi)}
> - Use an arbitrary number of linear inequalities
> - Subsume interval domain: x : [l, h] ⟺ x ≤ h ∧ −x ≤ −l
> - Subsume linear equalities: e = b ⟺ e ≤ b ∧ −e ≤ −b
>
> (각주 2: Automatic discovery of linear restraints among variables of a program (Cousot and Halbwachs, 1978))

### 번역
> - **선형 부등식 도메인**: 상태 = ⊥ 또는 **선형 부등식들의 연립** `⋀ (∑ a_{i,j} xj ≤ bi)`
> - **임의 개수**의 선형 부등식 사용 (등식 도메인은 최대 n개였지만 부등식은 제한 없음)
> - **구간 도메인을 포함**: `x∈[l,h]` ⟺ `x≤h ∧ −x≤−l`
> - **선형 등식 도메인을 포함**: `e=b` ⟺ `e≤b ∧ −e≤−b`
> - (각주: Cousot & Halbwachs 1978, "다면체 도메인")

### 해설

**개념 설명 — 가장 표현력 강한 도메인: 다면체(Polyhedra)**

부등식 도메인은 상태를 **선형 부등식들의 연립**으로 표현합니다. 기하적으로 각 부등식은 **반공간(half-space)**, 그 교집합은 **볼록 다면체(convex polyhedron)**입니다.

표현력이 막강합니다:
- **구간 도메인 포함**: `x∈[l,h]`는 `x≤h ∧ −x≤−l` 두 부등식으로 표현 → 구간 분석이 할 수 있는 모든 것을 함.
- **등식 도메인 포함**: `e=b`는 `e≤b ∧ e≥b` 두 부등식 → 등식 분석도 포함.

즉 **다면체 도메인 ⊇ 등식 도메인 ⊇ 구간 도메인** (표현력 순). 슬라이드 4의 배열 경계(`z<x`)도 이제 표현 가능. 대신 비용이 큽니다(부등식 개수 무제한 → 무한 높이 격자, 진짜 위드닝 필요 — 슬라이드 38).

**각주**: Cousot & Halbwachs(1978). **다면체(polyhedra) 분석**의 고전. 추상 해석의 대표적 관계형 도메인.

**슬라이드 연결**: 2차원 부등식의 기하가 슬라이드 30.

## 슬라이드 30: 2-Dimensional Linear Inequalities

### 원문 내용
> - Var = {x, y}
> - −3 ≤ x ∧ 3y ≤ x + 6 ∧ x − 5 ≤ 4y

### 번역
> 변수 {x,y}에서 세 부등식 `−3≤x`, `3y≤x+6`, `x−5≤4y`의 연립 → 평면에서 **세 직선으로 둘러싸인 볼록 영역**(띠 모양).

### 해설

**개념 설명**

각 부등식이 반평면(직선의 한쪽)이고, 셋의 교집합이 **볼록 다면체**(여기선 무한히 뻗는 띠 모양 영역). 등식(직선·점)보다 훨씬 풍부한 영역을 표현합니다. 부등식이라 "구간 같은 범위"와 "변수 간 비례 관계"를 동시에 담을 수 있음. 행렬 표현이 슬라이드 31~32.

## 슬라이드 31: State Representation: Matrix

### 원문 내용
> - Matrix representation: AX ≤ B
>   - where X is a vector of program variables
>   - ≤ is component-wise

### 번역
> - **행렬 표현**: `AX ≤ B` (X는 변수 벡터, ≤는 성분별 비교)

### 해설
등식의 `AX=B`(슬10)와 평행하게, 부등식은 `AX≤B`. 각 행이 부등식 하나, ≤는 벡터 성분별로 적용. 행렬로 다면체를 "제약 집합(H-표현)"으로 나타냄. 예가 슬라이드 32.

## 슬라이드 32: Matrix Representation: Example

### 원문 내용
> - −3 ≤ x ∧ 3y ≤ x + 6 ∧ x − 5 ≤ 4y
> - [[−1,0],[−1,3],[1,−4]](x y)ᵀ ≤ (3 6 5)ᵀ

### 번역
> 세 부등식을 `≤` 형태로 정리(−3≤x → −x≤3 등)해 행렬 `[[−1,0],[−1,3],[1,−4]]`, 우변 (3,6,5)ᵀ로 `AX≤B` 표현.

### 해설
슬라이드 30의 부등식을 표준형 `AX≤B`로. 각 부등식을 `... ≤ 상수`로 옮겨 행렬화. 슬라이드 11(등식)의 부등식판. 기하(생성) 표현은 슬라이드 33.

## 슬라이드 33: State Representation: Geometric

### 원문 내용
> - A set of points P0, ..., Pn and a set of vectors U0, ..., Um
>   - where {∑ λi Pi + ∑ μj Uj | ∑ λi = 1 ∧ λi, μj ≥ 0} is the set of solutions

### 번역
> - **기하 표현**: 점들 P0,...,Pn(꼭짓점)과 벡터들 U0,...,Um(무한 방향)
>   - 해집합 = `{∑ λi Pi + ∑ μj Uj | ∑λi=1, λi≥0, μj≥0}` — 즉 꼭짓점들의 **볼록 결합(convex combination)**에 방향들의 **음이 아닌 결합(conic)**을 더한 것

### 해설

**개념 설명 — 다면체의 생성 표현 (V-표현)**

등식의 기하 표현(점+자유 방향, 슬13)과 달리, 다면체는 **꼭짓점(Pi) + 무한히 뻗는 방향(Uj, ray)**으로 표현합니다. 제약 조건이 미묘합니다:
- `∑λi=1, λi≥0`: 꼭짓점들의 **볼록 결합** — 꼭짓점들로 둘러싸인 영역(다각형 내부).
- `μj≥0`: 방향은 **한 방향으로만**(ray) — 부등식은 한쪽으로 무한히 뻗으므로(등식은 양방향 자유였음).

이것이 다면체의 **V-표현(vertex/ray)**이고, 행렬은 **H-표현(half-space)**. 두 표현은 이중적이며, join은 V-표현이 편리(슬36). 예가 슬라이드 34.

## 슬라이드 34: Geometric Representation: Example

### 원문 내용
> - −3 ≤ x ∧ 3y ≤ x + 6 ∧ x − 5 ≤ 4y
> - P0 = (−3, −2), P1 = (−3, 1), U0 = (4, 1), U1 = (3, 1)

### 번역
> 슬라이드 30의 띠 영역을, 두 꼭짓점 P0=(−3,−2), P1=(−3,1)과 두 무한 방향 U0=(4,1), U1=(3,1)으로 표현. (왼쪽 변 x=−3에서 두 꼭짓점, 오른쪽으로 두 방향으로 무한히 뻗음.)

### 해설

**개념 설명**

띠 모양 영역(슬30)의 V-표현: 왼쪽 끝(x=−3)에 두 꼭짓점, 거기서 오른쪽 위로 두 방향(U0,U1)으로 무한히 뻗습니다. 꼭짓점들의 볼록결합(왼쪽 변)에 방향들의 conic 결합(오른쪽 확장)을 더하면 전체 띠. H-표현(슬32)과 V-표현(슬34)이 같은 다면체의 두 얼굴. 격자 연산: 순서(슬35), join(슬36).

## 슬라이드 35: Order

### 원문 내용
> - s1 ⊆ s2 iff solution set of s1 is a subset of s2
> - Where s1 is represented by P0,...,Pn, U0,...,Um and s2 by A', B', check if A'Pi ≤ B' for all i and A'Uj ≤ 0 for all j

### 번역
> - **순서 s1 ⊆ s2**: s1을 V-표현(점·방향), s2를 H-표현(A',B')으로 둘 때: **모든 꼭짓점 Pi에 대해 A'Pi ≤ B'** (점들이 s2 안에 있음)이고 **모든 방향 Uj에 대해 A'Uj ≤ 0** (방향들이 s2를 벗어나지 않음)

### 해설

**개념 설명**

등식의 순서 판정(슬16)의 부등식판. 차이는 `=0`이 `≤`로 바뀐 것:
- **A'Pi ≤ B'**: s1의 모든 꼭짓점이 s2의 모든 부등식 만족.
- **A'Uj ≤ 0**: s1의 모든 무한 방향이 s2의 부등식을 더 위반하지 않음(방향으로 가도 s2 안에 머묾).

볼록성 덕분에 꼭짓점과 방향만 검사하면 전체 영역의 포함이 보장됩니다(볼록 집합의 핵심 성질). join은 슬라이드 36.

## 슬라이드 36: Join

### 원문 내용
> - Where s1 is P0,...,Pn, U0,...,Um and s2 is P'0,...,P'n, U'0,...,U'm, use P0,...,Pn, P'0,...,P'n as points and U0,...,Um, U'0,...,U'm as vectors, but normalize them

### 번역
> - **join(s1 ⊔ s2)**: 두 다면체의 V-표현에서, **모든 꼭짓점을 합치고**(P들 + P'들) **모든 방향을 합쳐**(U들 + U'들) 정규화 → 두 다면체를 모두 포함하는 **볼록 껍질(convex hull)**

### 해설

**개념 설명 — 볼록 껍질 (join의 기하)**

다면체의 join은 **볼록 껍질(convex hull)** — 두 다면체를 모두 감싸는 가장 작은 볼록 집합입니다. V-표현이라 간단: 양쪽 꼭짓점·방향을 **모두 모아** 하나의 점·방향 집합으로(정규화로 불필요한 것 제거).

**중요한 부정확성**: 두 다면체의 합집합은 보통 볼록이 아닌데(예: 떨어진 두 영역), join은 그 사이를 **메워** 볼록하게 만듭니다. 그래서 실제보다 넓어질 수 있습니다(과근사). 이는 다면체 도메인이 **볼록 영역만** 표현하는 데서 오는 한계 — 하지만 안전(sound). 슬라이드 37이 예.

## 슬라이드 37: Join — Example

### 원문 내용
> - s1: P0=(0,1), U0=(0,1), U1=(1,0)
> - s2: P'0=(1,0), U'0=(0,1), U'1=(1,0)
> - s1 ⊔ s2: P''0=(1,0), P''1=(0,1), U''0=(1,0), U''1=(0,1)

### 번역
> s1(꼭짓점 (0,1), 위·오른쪽으로 뻗는 영역)과 s2(꼭짓점 (1,0)에서 같은 방향). join: 두 꼭짓점 (0,1),(1,0)과 두 방향을 합침 → 두 영역을 감싸는 볼록 껍질(그림에서 더 넓은 영역).

### 해설

**개념 설명**

두 다면체의 꼭짓점을 모두 모으니 join의 꼭짓점은 (1,0),(0,1) 둘, 방향은 (1,0),(0,1). 결과는 두 원래 영역 + 그 사이를 메운 볼록 영역. 세 번째 그림에서 보듯, 두 입력보다 넓어진(과근사) 볼록 껍질. join이 볼록성을 유지하느라 약간의 정밀도를 양보함을 보여 줍니다. 무한 높이라 위드닝이 진짜 필요(슬38).

## 슬라이드 38: Widening

### 원문 내용
> - The lattice has an infinite height
> - Same principle as for intervals
>   - Keep stable inequalities

### 번역
> - 부등식 격자는 **무한 높이** (등식과 달리)
> - **구간 위드닝과 같은 원리**: **안정적인(변하지 않는) 부등식만 유지**

### 해설

**개념 설명 — 진짜 위드닝이 필요한 이유**

등식 도메인은 유한 높이라 join만으로 종료됐지만(슬21), **부등식 도메인은 무한 높이**입니다 — 부등식 개수에 제한이 없고, 경계가 `x≤1, x≤2, x≤3, ...`처럼 무한히 늘 수 있어 고정점에 영영 도달 못 할 수 있습니다(강의 9의 구간 루프와 동일 문제).

해법은 강의 9의 위드닝과 같은 원리: 두 연속 상태를 비교해 **변하지 않고 안정적인 부등식만 남기고, 계속 변하는(커지는) 부등식은 버림**(∞로 보냄). 그러면 유한 단계에서 종료. 예가 슬라이드 39.

## 슬라이드 39: Widening — Example

### 원문 내용
> - s1: 2y ≤ x − 2 ∧ 2y ≤ −x + 6 ∧ y ≥ 0
> - s2: 2y ≤ x − 2 ∧ 2y ≤ −x + 10 ∧ y ≥ 0
> - s1 ∇ s2: 2y ≤ x − 2 ∧ y ≥ 0

### 번역
> s1, s2를 비교: `2y≤x−2`와 `y≥0`은 **둘 다 동일(안정)** → 유지. `2y≤−x+6`이 `2y≤−x+10`으로 **느슨해짐(변함)** → 버림. 위드닝 결과 **`2y≤x−2 ∧ y≥0`**(불안정한 부등식 제거).

### 해설

**개념 설명**

위드닝 `s1 ∇ s2`: 두 상태의 부등식을 비교해, **양쪽에서 똑같이 성립하는(안정적)** 것만 남깁니다. 여기서 `2y≤x−2`와 `y≥0`은 변화 없어 유지, `2y≤−x+6 → −x+10`은 경계가 움직였으므로(루프가 영역을 넓히는 중) **제거**(무한대로 보냄). 결과는 위쪽 경계가 사라진 더 넓은 영역. 이렇게 "계속 움직이는 경계를 포기"해 종료를 보장합니다 — 강의 9 구간 위드닝의 다면체판. 분기·대입은 슬40~43.

## 슬라이드 40: Control-Sensitivity

### 원문 내용
> - If a condition is defined by a linear (in)equality, we add it to the state and normalize it
> - Produce ⊥ if unsatisfiable

### 번역
> - 조건이 선형 **등식 또는 부등식**이면, 그것을 상태에 **추가**하고 정규화
> - 현재 상태와 **모순이면 ⊥**

### 해설

**개념 설명**

등식 도메인의 control-sensitivity(슬22)와 달리, 부등식 도메인은 **부등식 조건도 직접 추가**할 수 있습니다(부등식을 표현할 수 있으니까!). `if z < x` 가지에선 `z < x`를 상태에 더해 정밀도를 높입니다 — 슬라이드 4의 배열 경계 검사가 이제 가능. 모순이면 ⊥(죽은 가지). 등식 도메인이 못 하던 것(부등식 조건 활용)을 다면체가 해냅니다. 대입은 슬41.

## 슬라이드 41: Assignments

### 원문 내용
> - Invertible: x_o = b + ∑ ai xi where a_o ≠ 0
>   - Substitute x_o with (1/a_o)(x_o − b − ∑_{i≠o} ai xi)
> - Non-invertible: x_o = b + ∑ ai xi where a_o = 0
>   - Drop inequalities on x_o and add new inequalities

### 번역
> - **가역 대입**(자기 계수≠0): 옛 x_o를 새 식으로 치환 (등식 도메인 슬24와 동일 원리)
> - **비가역 대입**(자기 계수=0): x_o에 관한 옛 부등식들을 **버리고**, 새 부등식들(x_o = ...를 ≤,≥로)을 추가

### 해설

**개념 설명**

등식 도메인의 대입 처리(슬24·26)와 같은 원리, 부등식판:
- **가역**(`x=x+1` 등): 옛 x를 새 x로 역산해 모든 부등식에 치환. 정보 보존.
- **비가역**(`x=y−z` 등): 옛 x의 부등식을 모두 버리고(복원 불가), 새 관계를 부등식으로 추가. 일부 정보 손실.

예가 슬라이드 42(가역)·43(비가역).

## 슬라이드 42: Invertible Assignment — Example

### 원문 내용
> - Current state: 2y ≤ x − 2 ∧ 2y ≤ −x + 6 ∧ y ≥ 0
> - Assignment: x = x + 4;
> - Updated state: 2y ≤ x − 6 ∧ 2y ≤ −x + 10 ∧ y ≥ 0

### 번역
> `x=x+4`(가역). 옛 x = 새 x − 4. 상태의 옛 x를 (x−4)로 치환: `2y≤(x−4)−2=x−6`, `2y≤−(x−4)+6=−x+10`, `y≥0` 유지. → 영역이 오른쪽으로 4만큼 평행이동.

### 해설

**개념 설명**

`x=x+4`는 x를 4 늘리므로 다면체가 x축으로 4 평행이동. 가역 치환으로 모든 부등식의 x를 x−4로 바꿔 정확히 반영(`x−2 → x−6` 등). 그림에서 영역이 오른쪽으로 이동. 관계(다면체 모양)는 그대로, 위치만 이동 — 가역 대입이 정보를 보존함을 보여 줍니다. 비가역은 슬43.

## 슬라이드 43: Non-Invertible Assignment — Example

### 원문 내용
> - Current state: y ≥ 1 ∧ y ≥ −x + 5 ∧ y ≤ x + 1
> - Assignment: y = x + 1;
> - Normalized: x ≥ 2
> - Updated state: x ≥ 2 ∧ y ≥ x + 1 ∧ y ≤ x + 1 (i.e., y = x + 1)

### 번역
> `y=x+1`(비가역, 우변에 y 없음). 먼저 y를 소거해 y 없는 제약 `x≥2`를 얻음(옛 y 정보 일부 보존). y 관련 옛 부등식 버리고 새 관계 y=x+1(즉 y≤x+1 ∧ y≥x+1) 추가 → `x≥2 ∧ y=x+1`.

### 해설

**개념 설명**

`y=x+1`은 비가역(옛 y 복원 불가). 절차: 옛 부등식들에서 y를 소거해 y 무관한 정보(`x≥2`)를 추출·보존 → 옛 y 부등식 폐기 → 새 등식 y=x+1을 두 부등식으로 추가. 결과 `x≥2 ∧ y=x+1` — 2D 영역이 한 직선(y=x+1의 x≥2 부분)으로 좁혀짐. 옛 y의 범위 정보는 일부 잃지만 새 관계는 정확. 전체 요약이 슬44.

## 슬라이드 44: Summary

### 원문 내용
> - Relational analyses track relationships among variables
> - The abstract domain of linear equalities represents states as conjunctions of linear equalities
> - The abstract domain of linear inequalities represents states as conjunctions of linear inequalities, subsumes intervals and equalities

### 번역
> - **관계형 분석**은 변수들 사이의 관계를 추적한다
> - **선형 등식 도메인**은 상태를 선형 등식들의 연립으로 표현
> - **선형 부등식(다면체) 도메인**은 상태를 선형 부등식들의 연립으로 표현하며, **구간과 등식 도메인을 모두 포함**한다

### 해설

**전체 정리 — 강의 16의 한 장 요약**

1. **관계형 vs 비관계형**: 변수 간 관계(x=y, z<x)를 기억하는가의 차이. 배열 경계·바이너리 분석에 필수(슬2~5).
2. **선형 등식 도메인(Karr)**: 등식 연립 = 아핀 부분공간(점·선·면). 행렬(AX=B)/기하(점+방향) 이중 표현. **유한 높이라 위드닝 불필요**. 부등식 조건은 표현 못 함(슬6~28).
3. **선형 부등식 도메인(Polyhedra, Cousot–Halbwachs)**: 부등식 연립 = 볼록 다면체. H-표현(AX≤B)/V-표현(꼭짓점+ray). join=볼록 껍질(과근사). **무한 높이라 위드닝 필요**. 구간·등식을 모두 포함(가장 강력), 부등식 조건도 활용(슬29~43).
4. 각 도메인마다 순서·join·위드닝·control-sensitivity·대입(가역/비가역)을 체계적으로 정의 — 추상 도메인 설계의 완전한 절차.

**도메인 표현력 위계**: 다면체 ⊇ 선형등식 ⊇ 구간 ⊇ 부호. 위로 갈수록 정밀·비용↑.

**다른 강의와의 연결 (파일 간 연결성)**

- ← **강의 5~6 (격자·갈루아)**: 각 도메인이 완비 격자, 순서·join·meet 정의. 관계형 = 변수 곱공간의 부분집합 추상화.
- ← **강의 9 (구간·위드닝)**: 다면체 위드닝은 구간 위드닝의 일반화("안정적 경계만 유지"). 구간은 다면체의 특수형.
- ← **강의 7~8 (데이터플로우)**: 전이 함수(대입·조건), join, 고정점 반복의 틀.
- ← **선형대수**: 행렬·아핀공간·볼록다면체. 이 강의의 수학적 기반.
- → **강의 17 (관계형 2)**: 더 효율적인 관계형 도메인(octagon 등) 또는 응용으로 확장 예상.

**가장 큰 교훈**: **관계형 분석은 변수를 따로 보지 않고 그들의 관계를 추적**하여, 비관계형이 놓치는 정밀한 사실(x=y, z<x)을 잡아냅니다. 표현력이 클수록(구간→등식→다면체) 정밀하지만 비용도 커지며, 다면체처럼 무한 높이 도메인은 위드닝으로 종료를 보장해야 합니다 — 정밀도-비용-종료의 삼각 균형이 도메인 설계의 핵심입니다.

## 마치며

강의 16은 "변수들의 **관계**를 추상화한다"는 한 단계 높은 분석으로 올라갑니다. 선형 등식(Karr)과 선형 부등식/다면체(Cousot–Halbwachs)라는 두 고전 도메인을 통해, 추상 도메인을 설계하는 전 과정(표현·순서·join·위드닝·전이)을 가장 정교한 형태로 실습했습니다. 특히 **등식 도메인은 유한 높이라 위드닝이 불필요**한 반면 **다면체는 무한 높이라 위드닝이 필수**라는 대비, 그리고 **join이 볼록 껍질로 과근사**하는 점이 핵심입니다. 시험에서는 (a) 행렬↔기하 표현 변환, (b) 두 상태의 join 계산(슬20·37), (c) 가역/비가역 대입 처리(슬25·27·42·43), (d) 등식 vs 다면체의 위드닝 필요성 차이(슬21 vs 38), (e) 도메인 표현력 위계가 단골입니다.
