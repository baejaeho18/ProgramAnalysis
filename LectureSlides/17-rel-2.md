## 강의 17 전체 조감도 (먼저 큰 그림)

강의 16에서 두 관계형 도메인을 봤습니다: **구간(비관계형, 약함·빠름)**과 **다면체(polyhedra, 가장 강함·매우 느림)**. 다면체는 표현력이 최고지만, 부등식 개수가 무제한이라 연산이 지수적으로 비쌀 수 있습니다(실무에서 큰 프로그램엔 부담).

강의 17은 그 **중간 지점**을 메우는 **팔각형 도메인(Octagon Domain, Miné 2006)**을 다룹니다. 핵심 제약: 부등식을 **`±x ± y ≤ c`** 형태(변수 둘, 계수는 ±1)로만 제한합니다. 그러면:
- 구간(`x ≤ c`)보다 표현력이 강하고(변수 간 차이·합 관계를 잡음),
- 다면체보다 표현력은 약하지만 **훨씬 빠름**(다항 시간, O(n³) 정규화).

기하적으로 두 변수 영역이 **팔각형(8변)**으로 표현되어 "octagon"입니다.

이 강의의 진짜 기술적 알맹이는 **차분 한계 행렬(Difference-Bound Matrix, DBM)**입니다. `±x±y≤c` 제약들을 행렬로 인코딩하고, 각 변수를 **양수 버전 x⁺, 음수 버전 x⁻**로 쪼개(2n×2n 행렬), 모든 연산(공집합 검사·정규화·순서·join·위드닝·대입)을 **그래프 알고리즘(Bellman–Ford, 최단경로)**으로 환원합니다. 즉 관계형 분석을 **그래프 문제로** 바꾸는 우아한 아이디어가 이 강의의 백미입니다.

선형대수보다는 **그래프(가중 그래프·음수 사이클·최단경로)**가 주된 도구입니다.

## 슬라이드 2: Octagon Domain

### 원문 내용
> - Var = {xi | i ∈ I}
> - State = {⊥} ∪ {⋀_{j∈J} c_{j,1} x_{j,1} + c_{j,2} x_{j,2} ≤ bj | c_{j,1}, c_{j,2} ∈ {−1, 0, 1}}
>
> (각주 1: The octagon abstract domain (Miné, 2006))

### 번역
> - 변수 집합 Var = {xi}
> - **상태** = ⊥ 또는 부등식들의 연립 `⋀ (c1·x1 + c2·x2 ≤ b)`인데, **계수 c1, c2 ∈ {−1, 0, 1}**로 제한
> - (각주: Miné 2006, "팔각형 추상 도메인")

### 해설

**개념 설명 — 계수를 ±1, 0으로 제한한 부등식**

팔각형 도메인은 다면체의 **제한판**입니다. 다면체는 임의 계수의 부등식(`3x + 5y ≤ 7`)을 허용했지만, 팔각형은 **계수를 {−1, 0, 1}로만** 제한합니다. 그래서 가능한 부등식은:
- 변수 하나: `±x ≤ c` (구간 경계)
- 변수 둘: `±x ± y ≤ c` (차이·합 관계)

이 제한 덕분에 표현력은 줄지만 **연산이 훨씬 빨라집니다**(DBM + 그래프 알고리즘으로 다항 시간). 정밀도와 비용의 절묘한 타협점.

**각주**: Miné(2006). 팔각형 도메인의 표준 참고문헌. 실무 정적 분석기(Astrée 등)에서 널리 쓰임.

**슬라이드 연결**: 허용되는 부등식 형태와 표현력이 슬라이드 3.

## 슬라이드 3: Octagon Domain — Properties

### 원문 내용
> - Only two forms of inequalities are allowed
>   - ±x ± y ≤ c
>   - ±x ≤ c
> - Subsumes interval domain
>   - x : [l, h] ⟺ x ≤ h ∧ −x ≤ −l

### 번역
> - **단 두 형태**의 부등식만 허용:
>   - `±x ± y ≤ c` (두 변수의 합/차)
>   - `±x ≤ c` (한 변수의 범위)
> - **구간 도메인을 포함**: `x∈[l,h]` ⟺ `x≤h ∧ −x≤−l`

### 해설

**개념 설명 — 표현력 위계에서의 위치**

허용 부등식:
- `±x ≤ c`: 구간(`x≤h`, `−x≤−l` = `x≥l`). → **구간 도메인을 포함**.
- `±x±y ≤ c`: 변수 간 차(`x−y≤c`)와 합(`x+y≤c`) 관계. → 구간이 못 하던 관계형 정보.

표현력 위계: **구간 ⊊ 팔각형 ⊊ 다면체**. 팔각형은 "변수 *쌍*의 차/합"까지만 보고, 다면체처럼 임의 선형결합(`3x+5y`)은 못 봅니다. 그래서 다면체보다 약하지만 훨씬 쌉니다. 기하적 모양이 슬라이드 4.

## 슬라이드 4: Intuition

### 원문 내용
> - Possible values of two variables are represented by an octagon (8 edges)
>   - x ≥ c1, x ≤ c2 (좌우 변)
>   - y ≥ c3, y ≤ c4 (상하 변)
>   - y ≥ x + c5, y ≤ x + c6 (대각선)
>   - y ≥ −x + c7, y ≤ −x + c8 (반대 대각선)

### 번역
> - 두 변수의 가능한 값은 **팔각형(8개 변)**으로 표현됨:
>   - `x≥c1, x≤c2`: 수직 두 변 (구간 x)
>   - `y≥c3, y≤c4`: 수평 두 변 (구간 y)
>   - `y≥x+c5, y≤x+c6`: 기울기 +1 대각선 두 변 (x−y 관계)
>   - `y≥−x+c7, y≤−x+c8`: 기울기 −1 대각선 두 변 (x+y 관계)

### 해설

**개념 설명 — 왜 "팔각형"인가**

두 변수 (x,y)의 영역을 그리면, 네 종류의 경계가 **8개의 변**을 만듭니다:
- 수직 2변(x 범위) + 수평 2변(y 범위) = 사각형(구간 도메인).
- 여기에 기울기 ±1의 대각선 4변(x±y 범위)이 모서리를 잘라 **팔각형**이 됩니다.

즉 팔각형 = 사각형(구간)의 네 모서리를 45° 대각선으로 깎은 모양. 대각선이 변수 간 관계(x−y, x+y)를 표현합니다. 이 8변이 도메인 이름의 유래. 슬라이드 5가 구간·다면체와 시각 비교.

## 슬라이드 5: Comparison

### 원문 내용
> - (x, y) = (1,4), (2,6), (3,1), (4,3), (5,5), (6,2)
> - Interval: x = [1,6], y = [1,6]
> - Linear inequalities (polyhedra): 3y ≥ x, y ≤ −3x+20, 3y ≤ −x+20, y ≤ 2x+2, 2y ≥ −3x+11
> - Octagon: x ≥ 1, x ≤ 6, y ≥ 1, y ≤ 6, y ≥ x−4, y ≤ x+4, y ≥ −x+4, y ≤ −x+10

### 번역
> 6개 점을 세 도메인으로 추상화:
> - **구간**: x∈[1,6], y∈[1,6] → 큰 사각형(점들을 헐겁게 감쌈).
> - **다면체**: 임의 기울기 부등식들 → 점들에 가장 딱 맞는 볼록 다각형(가장 정밀).
> - **팔각형**: 구간 + ±1 대각선 → 사각형 모서리를 깎은 팔각형(중간 정밀도).

### 해설

**개념 설명 — 세 도메인의 정밀도 시각 비교 (핵심 슬라이드)**

같은 6개 점을 감싸는 영역:
- **구간(사각형)**: 가장 헐거움. 점들의 x·y 범위만 봄. 가장 빠르고 가장 부정밀.
- **다면체(임의 다각형)**: 점들에 가장 밀착. 임의 기울기 변을 쓸 수 있어 가장 정밀. 하지만 가장 비쌈.
- **팔각형(8변)**: 구간 사각형의 네 모서리를 45° 대각선으로 깎아 다면체에 더 가까워짐. 정밀도·비용 모두 중간.

이 그림이 강의 16~17 전체의 결론을 압축합니다: **정밀도 구간 < 팔각형 < 다면체, 비용도 같은 순서**. 팔각형은 "구간보다 똑똑하지만 다면체보다 싼" 실용적 선택. 슬라이드 6~7이 응용 사례(강의 16의 동기 재방문).

## 슬라이드 6: Use Case 1: Dynamically Sized Arrays

### 원문 내용
> ```
> x = input();
> y = [0; x];
> if z <= x - 1 {
>   y[z] = 1;
> }
> ```
> - z − x ≤ −1

### 번역
> 크기 x인 배열 `y`, `z ≤ x−1`일 때만 `y[z]` 접근. 이 조건은 팔각형 제약 **`z − x ≤ −1`**(즉 z < x)로 정확히 표현됨 → 배열 경계 안전 보장.

### 해설

**개념 설명**

강의 16 슬라이드 4의 배열 경계 예제 재방문. 핵심 조건 `z < x`는 **`z − x ≤ −1`** 형태로, 정확히 팔각형 제약(±x±y≤c, 여기선 z−x≤−1)입니다. 즉 **배열 경계 검사는 팔각형으로 충분**합니다 — 다면체까지 안 가도 됨. 팔각형이 실용적으로 유용한 이유: 흔한 검사(인덱스<크기)가 변수 차이 형태라 팔각형에 딱 맞습니다.

## 슬라이드 7: Use Case 2: Binary Analysis

### 원문 내용
> ```
> x = sp - 4;
> *x = 0;
> y = sp - 4;
> z = *y;
> ```
> - x ≥ sp − 4, x ≤ sp − 4
> - y ≥ sp − 4, y ≤ sp − 4
> - x − y ≥ 0, x − y ≤ 0

### 번역
> 강의 16의 바이너리 예제. `x=sp−4`는 `x≥sp−4 ∧ x≤sp−4`(즉 x=sp−4), y도 마찬가지. 이로부터 **`x−y≥0 ∧ x−y≤0`** 즉 x=y를 팔각형이 추론 → `*x`와 `*y`가 같은 위치.

### 해설

**개념 설명**

스택 포인터 상대 주소(`sp−4`)도 팔각형 제약(`x − sp ≤ −4 ∧ sp − x ≤ 4`)으로 표현됩니다. x=sp−4, y=sp−4로부터 **x=y**(즉 x−y≤0 ∧ x−y≥0)를 도출 → 두 접근이 같은 메모리. 바이너리 분석에서 필요한 관계(변수 = 포인터 − 상수, 두 변수 같음)가 모두 변수 차 형태라 팔각형으로 충분. 강의 16의 두 동기를 팔각형이 효율적으로 해결함을 보여 줍니다.

**슬라이드 연결**: 이제 팔각형을 효율적으로 구현하는 핵심 자료구조 — DBM(슬라이드 8).

## 슬라이드 8: Difference-Bound Matrices

### 원문 내용
> - Potential constraint: xj − xi ≤ c
> - A set of potential constraints can be represented by a N × N difference-bound matrix (DBM) m:
>   - m_ij = c if xj − xi ≤ c; ∞ otherwise

### 번역
> - **포텐셜 제약(potential constraint)**: `xj − xi ≤ c` (두 변수의 *차*에 대한 상한)
> - 포텐셜 제약들의 집합을 **N×N 차분 한계 행렬(DBM)** m으로 표현:
>   - `m_ij = c` (제약 `xj − xi ≤ c`가 있으면), 없으면 `∞`

### 해설

**개념 설명 — 차이 제약을 행렬로**

먼저 **차이 제약(difference constraint)** `xj − xi ≤ c`만 생각합니다(합 제약은 슬라이드 11에서 확장). 이를 **행렬 m**으로 저장: `m_ij`는 "xj − xi의 상한". 제약이 없으면 ∞(상한 무제한).

예: `x − y ≤ 3`이면 m의 해당 칸이 3. 이 행렬 표현(DBM)이 팔각형 연산을 그래프 알고리즘으로 바꾸는 열쇠입니다. 차이 제약은 **그래프의 간선**으로 볼 수 있기 때문(슬라이드 9).

**배경 지식**: "potential"은 그래프 이론의 포텐셜 함수에서 온 용어. 차이 제약 시스템은 최단경로 문제와 동치라는 고전 결과가 이 도메인의 기반입니다.

**슬라이드 연결**: DBM을 그래프로 보는 관점이 슬라이드 9.

## 슬라이드 9: Potential Graphs

### 원문 내용
> - For a DBM m, its potential graph is a weighted graph where
>   - Node = Var
>   - Edge = {(xi, xj) | m_ij < ∞}
>   - weight(xi, xj) = m_ij
> - A constraint xi − xj ≤ c is drawn as xj →^c xi

### 번역
> - DBM m의 **포텐셜 그래프(potential graph)**: 가중 방향 그래프
>   - 노드 = 변수들
>   - 간선 = `m_ij < ∞`인 (xi, xj) 쌍
>   - 간선 가중치 = `m_ij`
> - 제약 `xi − xj ≤ c`는 **`xj →^c xi`** (xj에서 xi로 가중치 c인 간선)으로 그림

### 해설

**개념 설명 — 차이 제약 = 그래프 간선 (핵심 관점)**

DBM을 **가중 그래프**로 봅니다: 변수가 노드, 제약 `xi − xj ≤ c`가 **xj에서 xi로 가중치 c인 간선**.

왜 이 방향·가중치인가? 차이 제약 시스템은 **최단경로 문제**와 동치입니다. `xi − xj ≤ c`는 "xj에 c를 더하면 xi의 상한"이라는 뜻으로, 그래프에서 경로를 따라 가중치를 더하면 변수 간 차이의 상한이 전파됩니다(슬라이드 20의 정규화 = 최단경로 계산). 이 그래프 관점이 모든 팔각형 연산을 그래프 알고리즘으로 환원하는 토대입니다. 예가 슬라이드 10.

## 슬라이드 10: DBM and Potential Graph — Example

### 원문 내용
> - Var = {x, y}
> - x − y ≤ 3
> - y − x ≤ −1
> - DBM: m = [[∞, −1], [3, ∞]]
> - Potential graph: x ⇄ y (x→y: −1, y→x: 3)

### 번역
> 제약 `x−y≤3`, `y−x≤−1`(즉 x−y≥1)을 DBM과 그래프로. 대각선은 ∞(자기 차이는 0이지만 제약 없음 표기), x→y 간선 −1, y→x 간선 3. 기하적으로는 `1 ≤ x−y ≤ 3`인 대각 띠.

### 해설

**개념 설명**

`x−y≤3`과 `y−x≤−1`(= x−y≥1)이 합쳐져 `1≤x−y≤3` — 기하적으로 기울기 1의 대각 띠. DBM은 두 제약을 두 칸에 저장, 그래프는 두 간선(x↔y). 이 작은 예가 "제약 ↔ 행렬 ↔ 그래프"의 삼위일체를 보여 줍니다. 그런데 지금까지는 **차이 제약(x−y)**만 다뤘습니다. 팔각형엔 **합 제약(x+y)**도 필요합니다(슬라이드 3). 그 확장이 슬라이드 11.

**슬라이드 연결**: 합 제약까지 다루는 확장 DBM이 슬라이드 11~14.

## 슬라이드 11: Extending DBMs

### 원문 내용
> - Var = {x0, ..., x_{n−1}}
> - V = {x0⁺, x0⁻, ..., x_{n−1}⁺, x_{n−1}⁻}
> - Within a potential constraint,
>   - a positive variable xi⁺ is interpreted as +xi
>   - a negative variable xi⁻ is interpreted as −xi

### 번역
> - 각 변수 xi를 **두 개로 분리**: 양수 버전 `xi⁺`(=+xi)와 음수 버전 `xi⁻`(=−xi)
> - 확장 변수 집합 V = {x0⁺, x0⁻, ...} (크기 2n)
> - 포텐셜 제약 안에서 xi⁺는 +xi로, xi⁻는 −xi로 해석

### 해설

**개념 설명 — 합 제약을 차이 제약으로 바꾸는 트릭 (핵심 아이디어)**

DBM은 **차이 제약(x−y)**만 다룰 수 있었습니다(슬8). 팔각형엔 **합 제약(x+y≤c)**도 있죠. 어떻게 합을 차이로 둔갑시킬까요?

비결: 각 변수 xi를 **양수 분신 xi⁺(=+xi)**와 **음수 분신 xi⁻(=−xi)**로 쪼갭니다. 그러면:
- `x + y ≤ c` = `x⁺ − y⁻ ≤ c` (왜냐면 y⁻=−y이니 x⁺−y⁻ = x−(−y) = x+y). **합이 차이가 됨!**
- `x − y ≤ c` = `x⁺ − y⁺ ≤ c`.
- `x ≤ c` = `x⁺ − x⁻ ≤ 2c` (x−(−x)=2x≤2c).

즉 변수를 두 배(2n)로 늘리면, **모든 팔각형 제약(±x±y≤c)이 확장 변수들의 차이 제약**이 됩니다. 그러면 슬8~10의 DBM·그래프 기법을 그대로 쓸 수 있죠. 이것이 팔각형 구현의 핵심 트릭입니다. 인덱싱 규약이 슬라이드 12.

**슬라이드 연결**: 2n 변수의 행렬 인덱싱이 슬라이드 12, 제약 변환표가 슬라이드 14.

---

## 슬라이드 12: Notation

### 원문 내용
> - Now, a DBM is a 2n × 2n matrix m where
>   - index 2i corresponds to xi⁺
>   - index 2i+1 corresponds to xi⁻
> - ī = i ⊕ 1 where ⊕ is bitwise XOR
>   - 2i̅ = 2i+1; 2i+1̅ = 2i
>   - If i corresponds to xa⁺ then ī corresponds to xa⁻ and vice versa

### 번역
> - 확장 DBM은 **2n×2n 행렬**:
>   - 인덱스 2i = xi⁺, 인덱스 2i+1 = xi⁻
> - **켤레 인덱스 ī = i XOR 1**:
>   - 짝수 2i의 켤레는 2i+1, 홀수 2i+1의 켤레는 2i
>   - i가 xa⁺이면 ī는 xa⁻ (양↔음 분신을 맞바꿈)

### 해설

**개념 설명 — 켤레 인덱스 (¯)**

확장 DBM은 2n×2n. 인덱싱: 짝수=양수 분신, 홀수=음수 분신. **켤레 연산 ī = i⊕1**(XOR 1)은 양수↔음수 분신을 맞바꿉니다(2i↔2i+1). 예: x⁺의 켤레는 x⁻. 이 켤레 개념이 다음 슬라이드의 "일관성(coherence)" 조건에 쓰입니다 — 같은 정보가 두 칸에 중복 저장되므로 둘이 일치해야 함.

---

## 슬라이드 13: Coherence

### 원문 내용
> - m is coherent if and only if m_ij = m_{j̄ī} for all i, j

### 번역
> - DBM m이 **일관적(coherent)**이다 ⟺ 모든 i,j에 대해 **m_ij = m_{j̄ī}** (켤레 인덱스끼리 대칭)

### 해설

**개념 설명 — 같은 제약의 두 표현이 일치해야 함**

확장 DBM에선 하나의 팔각형 제약이 **두 칸에 중복** 나타납니다. 예: `x+y≤c`는 `x⁺−y⁻≤c`이자 `y⁺−x⁻≤c`(같은 제약을 변수 순서 바꿔 쓴 것). 따라서 두 칸이 같은 값을 가져야 모순이 없습니다.

**일관성 조건 `m_ij = m_{j̄ī}`**: 인덱스 (i,j)의 칸과 그 켤레 (j̄, ī)의 칸이 같아야 함. 이는 "같은 제약을 두 번 적은 것이 서로 어긋나지 않음"을 보장합니다. 팔각형 DBM은 항상 이 대칭을 유지해야 올바릅니다. 제약 변환 규칙이 슬라이드 14.

---

## 슬라이드 14: Representing Constraints

### 원문 내용
> | Over Var | Over V |
> |---|---|
> | x − y ≤ c | x⁺ − y⁺ ≤ c, y⁻ − x⁻ ≤ c |
> | x + y ≤ c | x⁺ − y⁻ ≤ c, y⁺ − x⁻ ≤ c |
> | x ≤ c | x⁺ − x⁻ ≤ 2c |

### 번역
> 원래 변수 제약(왼쪽)을 확장 변수 V의 차이 제약(오른쪽)으로 변환:
> - `x−y≤c` → `x⁺−y⁺≤c` 및 `y⁻−x⁻≤c` (일관성 때문에 두 칸)
> - `x+y≤c` → `x⁺−y⁻≤c` 및 `y⁺−x⁻≤c`
> - `x≤c` → `x⁺−x⁻≤2c` (x−(−x)=2x≤2c)

### 해설

**개념 설명 — 변환표 (슬11의 트릭을 표로)**

세 종류 팔각형 제약을 확장 변수 차이 제약으로 변환:
- **차이 `x−y≤c`**: `x⁺−y⁺≤c`. 일관성(슬13) 때문에 켤레 `y⁻−x⁻≤c`도 함께.
- **합 `x+y≤c`**: `x⁺−y⁻≤c`(y⁻=−y이므로 x+y). 켤레 `y⁺−x⁻≤c`.
- **단일 `x≤c`**: `x⁺−x⁻≤2c`(x⁺−x⁻=x−(−x)=2x).

각 제약이 일관성을 위해 **두 칸**(또는 단일은 한 칸)에 들어갑니다. 이 표대로 채우면 모든 팔각형 제약이 2n×2n DBM의 차이 제약이 되어, 그래프 알고리즘 적용 준비 완료. 예가 슬라이드 15~16.

## 슬라이드 15: Extended DBM — Example (Constraints)

### 원문 내용
> - Var = {x, y}
> - x − y ≤ 2
> - x + y ≤ 3
> - x ≥ 1

### 번역
> 세 제약 `x−y≤2`, `x+y≤3`, `x≥1`의 연립 → 기하적으로 (차이·합·범위로 둘러싸인) 작은 영역.

### 해설
팔각형의 세 종류 제약(차이·합·단일)이 모두 등장하는 예. 그림에서 세 직선으로 잘린 볼록 영역. 이를 확장 DBM과 그래프로 옮긴 것이 슬라이드 16.

## 슬라이드 16: Extended DBM — Example (Matrix and Potential Graph)

### 원문 내용
> - V = {x⁺, x⁻, y⁺, y⁻}
> - x⁺ − y⁺ ≤ 2; y⁻ − x⁻ ≤ 2; x⁺ − y⁻ ≤ 3; y⁺ − x⁻ ≤ 3; x⁻ − x⁺ ≤ −2
> - m = [[∞,−2,∞,∞],[∞,∞,3,2],[2,∞,∞,∞],[3,∞,∞,∞]]
> - Potential graph: x⁺ ↔ y⁺ (2), x⁻ → x⁺(−2), x⁺↔y⁻/x⁻↔y⁺ (3들)

### 번역
> 슬라이드 15의 제약을 변환표(슬14)로 확장: `x−y≤2`→`x⁺−y⁺≤2` 등, `x≥1`(=−x≤−1)→`x⁻−x⁺≤−2`. 4×4 DBM과 4노드 포텐셜 그래프로 표현.

### 해설

**개념 설명**

세 원본 제약이 슬라이드 14 변환표로 확장 변수 차이 제약 5개(일관성 켤레 포함)가 되고, 4×4 DBM과 4노드(x⁺,x⁻,y⁺,y⁻) 가중 그래프로 인코딩됩니다. `x≥1`이 `x⁻−x⁺≤−2`로 변환된 점(단일 제약 규칙) 주목. 이제 이 DBM/그래프 위에서 모든 도메인 연산을 정의합니다: 공집합 검사(슬17), 정규화(슬19), 순서·join·위드닝(슬22~24), 대입(슬27~).

**슬라이드 연결**: 첫 연산 — 상태가 ⊥(모순)인지 검사하는 공집합 테스트가 슬라이드 17.

## 슬라이드 17: Emptiness Test

### 원문 내용
> - Checks whether the state is actually ⊥
> - A state can be considered ⊥ if its potential graph has a cycle with a strictly negative weight
> - Uses Bellman–Ford algorithm

### 번역
> - 상태가 실제로 **⊥(해가 없음)**인지 검사
> - 포텐셜 그래프에 **가중치 합이 음수인 사이클(negative-weight cycle)**이 있으면 ⊥로 간주
> - **Bellman–Ford 알고리즘** 사용

### 해설

**개념 설명 — 음수 사이클 = 모순 (그래프로 모순 검출)**

차이 제약 시스템이 **모순(해 없음)**일 조건은 그래프 이론의 고전 결과로 환원됩니다: **포텐셜 그래프에 음수 가중치 사이클이 있으면 모순**.

직관: 사이클 `x→y→...→x`의 가중치 합이 음수면, 이를 따라가면 `x − x ≤ (음수)` 즉 `0 ≤ (음수)`라는 모순이 도출됩니다. 예: `x−y≤1`(x→y:?)과 `y−x≤−2`를 합치면 `0 = (x−y)+(y−x) ≤ 1+(−2) = −1`, 모순 → 해 없음(⊥).

음수 사이클 탐지는 **Bellman–Ford 알고리즘**(O(VE))으로 합니다 — 음수 간선이 있는 그래프의 최단경로/음수사이클 표준 알고리즘. 관계형 도메인의 공집합 검사가 **그래프 알고리즘**이 되는 우아한 환원. 예가 슬라이드 18.

---

## 슬라이드 18: Emptiness Test — Example

### 원문 내용
> - x − y ≤ 1
> - x − y ≥ 2  (i.e., y − x ≤ −2)
> - V = {x⁺,x⁻,y⁺,y⁻}
> - x⁺−y⁺≤1; y⁻−x⁻≤1; y⁺−x⁺≤−2; x⁻−y⁻≤−2
> - (그래프: x⁺↔y⁺ 사이클 1+(−2)=−1 < 0)

### 번역
> `x−y≤1`이면서 `x−y≥2`(모순!). 확장하면 x⁺↔y⁺ 사이에 가중치 1과 −2인 두 간선 → 사이클 합 `1+(−2)=−1 < 0` → **음수 사이클 → ⊥**.

### 해설

**개념 설명**

`x−y≤1`과 `x−y≥2`는 명백히 모순(차이가 1 이하이면서 2 이상일 수 없음). 그래프에서 x⁺→y⁺(가중치 −2)와 y⁺→x⁺(가중치 1)이 사이클을 이루고 합이 −1<0 → Bellman–Ford가 음수 사이클 검출 → 상태는 ⊥. 모순이 음수 사이클로 정확히 드러납니다. 다음은 정규화(슬19).

---

## 슬라이드 19: Normalization

### 원문 내용
> - Two DBMs may represent constraint sets with the same solution set
> - We can normalize DBMs so that a single solution set is represented by a unique DBM

### 번역
> - 서로 다른 DBM이 **같은 해집합**을 표현할 수 있다(중복 표현)
> - DBM을 **정규화(normalize)**하면, 하나의 해집합이 **유일한 DBM**으로 표현됨

### 해설

**개념 설명 — 표준형으로 만들기 (왜 필요한가)**

같은 영역을 여러 제약 집합이 표현할 수 있습니다(예: `x−y≤1`만 적든, 거기에 함의되는 `x−z≤3`을 더 적든 같은 영역). 비교(순서·동치)를 정확히 하려면 **표준형(정규형)**이 필요합니다.

정규화 = **모든 함의된(implied) 제약을 명시적으로 채워 넣기** = 그래프의 **최단경로 닫힘(shortest-path closure)**. 모든 변수 쌍 사이의 가장 강한(최단경로) 차이 제약을 계산해 DBM을 채웁니다(Floyd–Warshall, O(n³)). 그러면 같은 해집합은 같은 정규 DBM이 됩니다. 예가 슬라이드 20~21.

**슬라이드 연결**: 정규화 = 함의 제약 도출, 예가 슬라이드 20(차이 합성)·21(범위→차이).

---

## 슬라이드 20: Normalization — Example 1

### 원문 내용
> - x − y ≤ 1, y − z ≤ 2  ⟹  x − y ≤ 1, y − z ≤ 2, x − z ≤ 3

### 번역
> `x−y≤1`과 `y−z≤2`로부터 (둘을 더하면) **`x−z≤3`**이 함의됨. 정규화는 이 숨은 제약을 명시적으로 추가.

### 해설

**개념 설명 — 차이 제약의 합성 = 최단경로**

`x−y≤1`과 `y−z≤2`를 더하면 `x−z≤3`(중간 y가 소거됨). 그래프로는 x→y(1), y→z(2) 경로를 따라 x→z의 최단경로 3. 정규화가 이런 **경로 합성**으로 모든 함의 제약을 채웁니다. 이로써 비교가 칸별(entrywise)로 정확해집니다(슬22). 범위와 차이의 합성은 슬라이드 21.

---

## 슬라이드 21: Normalization — Example 2

### 원문 내용
> - x ≤ 1, y ≥ 2  ⟹  x ≤ 1, y ≥ 2, x − y ≤ −1

### 번역
> `x≤1`과 `y≥2`(즉 −y≤−2)로부터 **`x−y≤−1`**(x−y ≤ 1−2 = −1)이 함의됨. 정규화가 추가.

### 해설

**개념 설명**

단일 변수 범위(`x≤1`, `y≥2`)에서도 **차이 제약이 함의**됩니다: x는 1 이하, y는 2 이상이므로 x−y ≤ 1−2 = −1. 정규화는 구간 정보로부터 변수 간 관계까지 도출합니다 — 팔각형이 구간보다 정밀한 이유의 한 단면(범위들이 결합해 차이 정보 생성). 확장 변수로는 x⁺,x⁻,y⁺,y⁻ 간 경로로 계산. 이제 정규형 DBM 위에서 순서를 정의(슬22).

## 슬라이드 22: Order

### 원문 내용
> - s1 ⊆ s2 iff solution set of s1 ⊆ solution set of s2
> - Where s1 is DBM m, s2 is DBM n, s1 ⊆ s2 iff m_ij ≤ n_ij for all i, j
> - Example: {x − y ≤ 1} ⊆ {x − y ≤ 2}

### 번역
> - **순서 s1 ⊆ s2**: 해집합 포함
> - **정규 DBM**으로 비교: `m_ij ≤ n_ij` (모든 칸에서 m이 n보다 작거나 같음)이면 s1 ⊆ s2
> - 예: `{x−y≤1}` ⊆ `{x−y≤2}` (더 빡빡한 상한이 더 좁은 영역)

### 해설

**개념 설명 — 순서가 칸별 비교로 (DBM의 장점)**

다면체에선 순서 판정이 복잡했지만(슬16-17 강의16), DBM에선 **단순한 칸별(entrywise) 비교**입니다: 정규화된 두 DBM에서 모든 칸이 `m_ij ≤ n_ij`이면 s1 ⊆ s2. 직관: 상한이 더 작으면(빡빡하면) 영역이 더 좁음. 예: `x−y≤1`(상한 1)이 `x−y≤2`(상한 2)보다 좁음 → 부분집합.

**왜 정규화가 필수인가**: 정규화 안 하면, 같은 영역인데 칸 값이 달라 비교가 틀릴 수 있습니다(함의 제약이 빠져서). 정규형이라야 칸별 비교가 해집합 포함과 일치. join·meet도 칸별(슬23).

---

## 슬라이드 23: Join and Meet

### 원문 내용
> - s1 ⊔ s2 represented by DBM l where l_ij = max(m_ij, n_ij)
> - s1 ⊓ s2 represented by DBM l where l_ij = min(m_ij, n_ij)
> - Example:
>   - {x−y≤1, z−w≤2} ⊔ {x−y≤2, z−w≤1} = {x−y≤2, z−w≤2}
>   - {x−y≤1, z−w≤2} ⊓ {x−y≤2, z−w≤1} = {x−y≤1, z−w≤1}

### 번역
> - **join(⊔)**: 칸별 **최댓값** `l_ij = max(m_ij, n_ij)` (느슨한 상한 채택 → 더 넓은 영역)
> - **meet(⊓)**: 칸별 **최솟값** `l_ij = min(m_ij, n_ij)` (빡빡한 상한 채택 → 더 좁은 영역)
> - 예: join은 각 제약의 더 큰 상한, meet은 더 작은 상한.

### 해설

**개념 설명 — join·meet도 칸별 (DBM의 우아함)**

다면체의 join(볼록 껍질, 복잡)과 달리, DBM의 join·meet은 **칸별 max/min**으로 끝납니다:
- **join(⊔, 두 영역을 모두 포함)**: 각 제약의 상한 중 **더 큰(느슨한) 것** → 합집합을 감싸는 더 넓은 영역. `max`.
- **meet(⊓, 두 영역의 교집합)**: 각 상한 중 **더 작은(빡빡한) 것** → 교집합. `min`.

예에서 보듯 join은 `{x−y≤2, z−w≤2}`(둘 다 느슨한 상한), meet은 `{x−y≤1, z−w≤1}`(둘 다 빡빡한 상한). 매우 단순·효율적 — 팔각형이 다면체보다 빠른 핵심 이유. (단 join 결과는 다시 정규화 필요.) 위드닝도 칸별(슬24).

## 슬라이드 24: Widening

### 원문 내용
> - Same principle as for intervals: Keep stable inequalities
> - s1 ∇ s2 represented by DBM l where
>   - l_ij = m_ij if n_ij ≤ m_ij; ∞ otherwise
> - Example: {x−y≤1, z−w≤2} ∇ {x−y≤2, z−w≤2} = {x−y≤∞, z−w≤2}

### 번역
> - **위드닝**: 구간과 같은 원리("안정적 부등식만 유지")
> - 칸별: `l_ij = m_ij` (n_ij ≤ m_ij, 즉 상한이 안 늘었으면 유지); 그 외(상한이 늘어남) → `∞`(버림)
> - 예: `x−y` 상한이 1→2로 **늘었으므로 ∞**(버림), `z−w`는 2→2로 **안정**이라 유지.

### 해설

**개념 설명 — 위드닝도 칸별 (무한 높이 종료 보장)**

팔각형도 (다면체처럼) 무한 높이라 위드닝이 필요합니다. 칸별로 간단히:
- 상한이 **안 늘었으면**(`n_ij ≤ m_ij`, 안정) → 유지.
- 상한이 **늘었으면**(불안정, 루프가 넓히는 중) → `∞`(제약 포기).

예: `x−y≤1`이 `x−y≤2`로 느슨해졌으니(루프가 차이를 키우는 중) → ∞로 보내 포기. `z−w`는 안정이라 유지. 강의 9·16의 위드닝 원리("계속 변하는 경계는 버림")가 DBM에선 칸별 연산으로 깔끔히 구현됩니다. 분기·대입은 슬25~30.

## 슬라이드 25: Control-Sensitivity

### 원문 내용
> - Condition: xa − xb ≤ c
>   - m'_ij = min(m_ij, c) if (j,i) ∈ {(2a,2b), (2b+1, 2a+1)}; m_ij otherwise
> - Condition: xa + xb ≤ c
>   - m'_ij = min(m_ij, c) if (j,i) ∈ {(2a,2b+1), (2b,2a+1)}; m_ij otherwise
> - Condition: xa ≤ c
>   - Equivalent to xa + xa ≤ 2c

### 번역
> - 조건 **`xa − xb ≤ c`**: 해당 두 칸(차이 제약 위치)을 `min(기존, c)`로 갱신(더 빡빡하면 반영), 나머지 유지
> - 조건 **`xa + xb ≤ c`**: 합 제약 위치 두 칸을 `min(기존, c)`로
> - 조건 **`xa ≤ c`**: `xa + xa ≤ 2c`와 동치로 처리

### 해설

**개념 설명 — 분기 조건을 DBM 칸에 반영**

`if` 조건(팔각형 형태)을 만나면, 해당 제약을 DBM에 **meet처럼 반영**합니다 — 그 제약 위치의 칸을 `min(기존 상한, 조건 상한)`으로(더 빡빡하면 영역이 좁아짐). 인덱스 (2a, 2b 등)는 슬라이드 12의 x⁺/x⁻ 인코딩에 따른 칸 위치입니다.

이로써 조건 분기에서 정밀도를 높입니다(강의 16 슬22·40과 같은 control-sensitivity). 단일 제약은 합 제약의 특수형(`xa+xa≤2c`)으로 환원. 조건 반영 후엔 음수 사이클 검사(슬17)로 모순(⊥)을 확인. 예가 슬라이드 26.

## 슬라이드 26: Control-Sensitivity — Example

### 원문 내용
> - State: x − y ≤ 2; Condition: x − y ≤ 3 ⟹ Updated: x − y ≤ 2
> - State: x − y ≤ 2; Condition: x − y ≤ 1 ⟹ Updated: x − y ≤ 1

### 번역
> - 상태 `x−y≤2`에 조건 `x−y≤3`(더 느슨): `min(2,3)=2` → 변화 없음(이미 더 빡빡).
> - 상태 `x−y≤2`에 조건 `x−y≤1`(더 빡빡): `min(2,1)=1` → `x−y≤1`로 좁아짐.

### 해설
조건이 기존보다 느슨하면 정보 추가 없음(이미 더 강한 제약 보유), 빡빡하면 영역이 좁아짐 — `min` 연산의 직관. 조건이 영역을 좁히거나(정밀화) 그대로 두는 모습. 대입 처리는 슬27(가역)·29(비가역).

## 슬라이드 27: Assignments (Invertible)

### 원문 내용
> - xa = xa + c
> - m'_ij = m_ij + (α_ij + β_ij)c where
>   - α_ij = 1 if j=2a; −1 if j=2a+1; 0 otherwise
>   - β_ij = −1 if i=2a; 1 if i=2a+1; 0 otherwise

### 번역
> - **가역 대입 `xa = xa + c`** (자기 자신에 상수 더하기):
>   - DBM의 각 칸을 `m_ij + (α_ij + β_ij)c`로 조정 — xa(=index 2a)나 xa⁻(=2a+1) 관련 칸들의 상한을 c만큼 평행이동

### 해설

**개념 설명 — 가역 대입 = 상한 평행이동**

`xa = xa + c`는 xa를 c만큼 옮기므로, xa가 관련된 모든 차이 제약의 상한도 그만큼 조정됩니다. 예: `xa − y ≤ b`였다면 새 xa = 옛 xa + c이므로 `xa − y ≤ b + c`. α,β는 "이 칸이 xa⁺(2a)를 더하는지 xa⁻(2a+1)를 빼는지"에 따라 +c/−c를 결정하는 부호 표시입니다. 본질은 **xa 관련 상한들을 c만큼 평행이동**(정보 보존, 가역). 예가 슬라이드 28.

## 슬라이드 28: Invertible Assignment — Example

### 원문 내용
> - State: x − y ≤ 1, x ≤ 2, z − x ≤ 3
> - Assignment: x = x + 1
> - Updated state: x − y ≤ 2, x ≤ 3, z − x ≤ 2

### 번역
> `x=x+1` 후, x가 든 제약들의 상한 조정: `x−y≤1`→`≤2`(x 늘어 차이 늘), `x≤2`→`≤3`, `z−x≤3`→`≤2`(x 늘어 z−x 줄). x 부호에 따라 +1 또는 −1.

### 해설

**개념 설명**

`x=x+1`로 x가 1 증가. x가 **양의 부호**로 든 제약(`x−y`, `x`)은 상한 +1, x가 **음의 부호**로 든 제약(`z−x`)은 상한 −1. 모든 x 관련 제약이 일관되게 평행이동되어 새 x의 관계를 정확히 반영(가역이라 손실 없음). 비가역은 슬29.

## 슬라이드 29: Assignments (Non-Invertible)

### 원문 내용
> - xa = xb + c (a ≠ b)
> - m'_ij =
>   - c if (j,i) ∈ {(2a,2b), (2b+1,2a+1)}
>   - −c if (j,i) ∈ {(2b,2a), (2a+1,2b+1)}
>   - m_ij if i,j ∉ {2a, 2a+1}
>   - ∞ otherwise

### 번역
> - **비가역 대입 `xa = xb + c`** (xa ≠ xb, 우변에 xa 없음):
>   - xa의 옛 제약을 모두 **버리고**(∞), 새 관계 `xa − xb = c`(즉 `xa−xb≤c` 및 `xb−xa≤−c`)를 해당 칸에 설정
>   - xa와 무관한 칸들(`i,j ∉ {2a,2a+1}`)은 유지

### 해설

**개념 설명 — 비가역 대입 = 옛 xa 제약 폐기 + 새 관계**

`xa = xb + c`는 우변에 xa가 없어 옛 xa 복원 불가(비가역). 그래서:
- xa 관련 **옛 칸들을 ∞로**(옛 제약 폐기 — 강의 16 슬26의 "drop"에 해당).
- 새 관계 `xa − xb = c`(차이가 정확히 c)를 두 칸에 설정.
- xa와 무관한 칸은 그대로.

옛 xa의 정보는 잃지만(예: 옛 `xa≤5`), 새 관계는 정확. 가역(평행이동·보존) vs 비가역(폐기·재설정)의 대비는 강의 16과 동일 구조. 예가 슬라이드 30.

## 슬라이드 30: Non-Invertible Assignment — Example

### 원문 내용
> - State: x − y ≤ 1, z − w ≤ 2
> - Assignment: x = y + 5
> - Updated state: x − y ≤ 5, y − x ≤ −5, z − w ≤ 2

### 번역
> `x=y+5`(비가역). 옛 `x−y≤1` 폐기, 새 관계 `x−y=5`(즉 `x−y≤5 ∧ y−x≤−5`) 설정. x 무관한 `z−w≤2`는 유지.

### 해설

**개념 설명**

`x=y+5`로 x의 옛 관계(`x−y≤1`)는 무효 → 폐기. 새로 `x−y=5`가 성립(x가 정확히 y+5). 두 부등식 `x−y≤5`, `y−x≤−5`로 등식을 표현. x와 무관한 `z−w≤2`는 보존. 옛 정밀 정보(x−y≤1)는 사라지지만 새 정확한 관계로 대체 — 비가역 대입의 전형. 전체 요약이 슬31.

## 슬라이드 31: Summary

### 원문 내용
> - Octagons capture constraints of the form ±x ± y ≤ c, strictly more expressive than intervals but cheaper than full polyhedra
> - Difference-bound matrices (DBMs), extended with xi⁺ and xi⁻ variables, encode octagonal states as 2n × 2n matrices
> - Potential graphs give a geometric view of DBMs; emptiness reduces to detecting a negative-weight cycle via Bellman–Ford
> - Order, join, meet, and widening on octagons reduce to entrywise comparisons on DBMs
> - Control-sensitivity and assignment transfer functions are defined index-wise on the DBM, with separate rules for invertible and non-invertible updates

### 번역
> - **팔각형**은 `±x±y≤c` 형태 제약을 잡으며, 구간보다 엄밀히 표현력이 강하지만 완전한 다면체보다 싸다
> - **차분 한계 행렬(DBM)**을 xi⁺·xi⁻ 변수로 확장해, 팔각형 상태를 2n×2n 행렬로 인코딩
> - **포텐셜 그래프**가 DBM의 기하적 관점을 주고, 공집합 검사는 **Bellman–Ford로 음수 사이클 탐지**로 환원
> - 팔각형의 순서·join·meet·위드닝은 모두 DBM의 **칸별(entrywise) 비교**로 환원
> - control-sensitivity와 대입 전이 함수는 DBM 인덱스별로 정의되며, 가역/비가역 갱신에 별도 규칙

### 해설

**전체 정리 — 강의 17의 한 장 요약**

1. **팔각형 도메인**: `±x±y≤c`로 제한. 구간 ⊊ 팔각형 ⊊ 다면체(표현력·비용). 기하적으로 8변 팔각형. 배열 경계·바이너리 분석에 충분(슬2~7).
2. **DBM**: 차이 제약 `xj−xi≤c`를 행렬로. 합 제약은 변수를 x⁺·x⁻로 쪼개 차이로 환원(2n×2n). 일관성 조건으로 중복 칸 일치(슬8~16).
3. **그래프 알고리즘으로 환원**: 포텐셜 그래프, 공집합=음수 사이클(Bellman–Ford), 정규화=최단경로 닫힘(Floyd–Warshall, O(n³))(슬17~21).
4. **연산이 칸별**: 순서(≤), join(max), meet(min), 위드닝(안 늘면 유지 아니면 ∞) — 모두 entrywise로 간단·효율(슬22~24).
5. **전이 함수**: control-sensitivity(min 반영), 가역 대입(평행이동·보존), 비가역 대입(폐기·재설정)(슬25~30).

**다른 강의와의 연결 (파일 간 연결성)**

- ← **강의 16 (관계형 1)**: 팔각형은 구간과 다면체의 중간. 같은 연산(순서·join·위드닝·대입 가역/비가역)을 더 효율적 표현으로. 표현력 위계 완성.
- ← **강의 9 (구간·위드닝)**: 위드닝 원리("안정적 제약만 유지")가 칸별로 재등장. 팔각형은 구간을 포함.
- ← **강의 5~6 (격자)**: DBM이 격자 구조, join=max·meet=min.
- ← **그래프 알고리즘 (Bellman–Ford, Floyd–Warshall)**: 공집합·정규화의 핵심 도구. 관계형 분석을 그래프 문제로 환원.
- → **강의 18~20 (추상 해석)**: 팔각형은 추상 해석의 대표적 수치 도메인. 갈루아 연결·건전성의 구체적 사례로 재등장 가능.

**가장 큰 교훈**: **팔각형은 "표현력을 적당히 제한해 효율을 얻는" 도메인 설계의 모범**입니다. `±x±y≤c`로 제한한 대가로, 모든 연산이 **그래프 알고리즘과 칸별 행렬 연산**으로 환원되어 다항 시간에 돌아갑니다. 특히 "변수를 x⁺·x⁻로 쪼개 합 제약을 차이 제약으로 바꾸는" 트릭과, "공집합=음수 사이클, 정규화=최단경로"라는 그래프 환원이 핵심 통찰입니다.

## 마치며

강의 17은 관계형 분석의 실용적 균형점 — **팔각형 도메인** — 을 제시합니다. 구간은 너무 약하고 다면체는 너무 비쌀 때, 팔각형이 변수 간 차/합 관계를 다항 시간에 잡아냅니다. 기술적 핵심은 **DBM과 그래프 알고리즘으로의 환원**: 관계형 제약을 가중 그래프로 보고, 모순 검출은 음수 사이클(Bellman–Ford)로, 정규화는 최단경로 닫힘으로, 나머지 연산은 칸별 행렬 연산으로 처리합니다. 시험에서는 (a) 팔각형/구간/다면체 표현력 비교(슬5), (b) 제약을 확장 DBM·포텐셜 그래프로 변환(슬14~16), (c) 음수 사이클로 공집합 판정(슬17~18), (d) 정규화로 함의 제약 도출(슬20~21), (e) 칸별 join/meet/위드닝 계산(슬23~24), (f) 가역/비가역 대입(슬28·30)이 단골입니다.
